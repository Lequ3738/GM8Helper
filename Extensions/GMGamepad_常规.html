常规

bool gamepad_dll_init(string path, [string databasePath])
仅适用于 DLL 版本。在使用DLL前，调用此函数进行初始化。
参数 path 是 DLL 的文件路径。可选参数 databasePath 是映射数据库文件 GamepadDatabase.txt 的路径。
返回是否初始化成功。

void gamepad_dll_free()
仅适用于 DLL 版本。游戏结束时，调用此函数释放DLL。

bool gamepad_update()
此扩展需要在游戏的主控对象中每步调用此函数来更新手柄状态。推荐在“步开始（Begin Step）”事件中调用此函数。
当游戏手柄插入设备（或将其移除）时，此函数在这一帧内返回 true，否则返回 false。
