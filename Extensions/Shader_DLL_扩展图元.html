扩展图元

由于 GM 自带的 draw_* 函数在每次调用时都会使用默认的顶点着色器，于是在使用自定义顶点着色器的时候，必须使用以下的扩展图元函数来绘制图像。

使用像素着色器的时候也可以用扩展图元，相对 GM 自带的 draw_primitive_* 和 draw_vertex_* 函数，新增了对法线，镜面颜色/透明度，不同纹理阶段的独立坐标的支持。

bool d3d_primitive_begin_ext(real primitive, bool textured)
开始绘制扩展图元，最大 8192 个顶点。textured 来定义是否使用纹理，使用 d3d_set_tex() 控制纹理。若无纹理，设为 false 并调用 d3d_set_tex_all(-1)。

注意：绘制时使用纹理坐标与普通方法不同，需为每个顶点单独指定坐标：

无纹理示例：

d3d_primitive_begin_ext(pr_trianglestrip, false);
  d3d_vertex_ext(...);
  d3d_vertex_ext(...);
  d3d_vertex_ext(...);
d3d_primitive_end_ext();

带纹理示例：

d3d_primitive_begin_ext(pr_trianglestrip, true);
  d3d_vertex_ext(...);
  d3d_vertex_ext_tex(...); // 定义每个阶段最多 8 组纹理坐标
  d3d_vertex_ext_next();   // 结束当前顶点定义
  d3d_vertex_ext(...);
  d3d_vertex_ext_tex(...);
d3d_primitive_end_ext();   // 绘制

这些函数不会直接影响纹理阶段，因此即使 textured 设为 true，仍可绘制无坐标的纹理图元。这样设计的目的是允许在顶点着色器中定义坐标。

bool d3d_vertex_ext(real x, real y, real z, real normalX, real normalY, real normalZ, real color, real alpha, real speccol, real specalpha)
设置顶点位置、法线、颜色/透明度和镜面颜色/透明度。镜面颜色/透明度仅在着色器使用时生效。

bool d3d_vertex_ext_tex(real stage, real xtex, real ytex)
设置顶点的纹理坐标。每个纹理阶段（共 8 个，索引 0-7）各有一组坐标。
注：准确来说此函数的 stage 是纹理坐标集编号，通过不同的 stage 值，分别在着色器中设置 t0 - t5（像素着色器）或 v7 - v14（顶点着色器）。由于此扩展将相同的纹理坐标集编号映射到相同的纹理阶段，为了简化概念，统一用纹理阶段来称呼。

bool d3d_vertex_ext_next()
结束当前顶点定义，开始下一个顶点。
注意：此函数只有在绘制时使用纹理才能使用，若绘制时无纹理，则不需要调用此函数。

bool d3d_primitive_end_ext()
结束图元绘制。

bool draw_primitive_begin_ext(real primitive, bool textured)
bool draw_vertex_ext(real x, real y, real col, real alpha, real speccol, real specalpha)
bool draw_vertex_ext_tex(real stage, real xtex, real ytex)
bool draw_vertex_ext_next()
bool draw_primitive_end_ext()
功能相同，仅适用于 2D 处理。
