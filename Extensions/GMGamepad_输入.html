bool gamepad_button_check(real device, real button)
此函数检测给定的游戏手柄按钮是否被按住。
若无特殊说明，以下说明皆适用于此页所记录的函数：
  1. 此函数不仅可以检测按钮，还可以检测摇杆是否不在原点上。
  2. 既可以使用游戏手柄按钮常量和游戏手柄摇杆常量，又可以使用原始索引和原始索引偏移常量。
  3. 若在使用原始索引和十字键索引偏移常量时，原始索引为 4 个一组，对同一个十字键进行描述。这 4 个索引从低到高分别描述十字键上键、十字键下键、十字键左键和十字键右键。
  4. 在受支持的手柄中，任意键常量均可按照预期使用；在不受支持的手柄中，任意键常量只能用于手柄的按钮（包括十字键，但不包括摇杆和扳机键，即 gp_anyaxis 失效，gp_any 只能用于按钮）。
bool gamepad_button_check_pressed(real device, real button)
此函数检测给定的游戏手柄按钮是否已被按下。请注意，此函数只会在第一次按下按钮时触发一次 。要再次触发它，必须先松开按钮，然后重新按下。如果您需要检查按钮的连续按下，则应使用函数 gamepad_button_check()。

bool gamepad_button_check_released(real device, real button)
此函数检测给定的游戏手柄按钮是否已释放。请注意，此函数只会在释放按钮时触发一次 。要再次触发它，必须先按下按钮，然后再次松开。

bool gamepad_button_check_direct(real device, real button)
此函数直接通过硬件检测给定的游戏手柄按钮是否被按住。

real gamepad_axis_value(real device, real axis)
您可以使用此函数从给定的游戏手柄插槽中获取不同摇杆的值。
您提供要检查的游戏手柄插槽索引，使用游戏手柄摇杆常量，或使用原始索引和原始索引偏移常量。对于每个可用的水平和垂直摇杆轴，返回值会在 -1 和 1 之间；对于每个可用的扳机键，返回值会在 0 和 1 之间。
请注意，返回值经过归一化处理，以考虑轴死区设置的值（使用函数 gamepad_set_axis_deadzone() 来设置）。此函数将始终返回一个介于 -1 和 0 之间或 0 和 1 之间的归一化值。例如，将死区设置为 0.2 意味着，当原始轴值超过 0.2 时，向右推动摇杆才会开始返回 0 到 1 之间的值——因此，当原始值为 0.2 时，返回值将为 0；当原始值为 0.5 时，返回值将为 0.375；或者，如果原始值为 0.9，则返回值将为 0.875。

bool gamepad_button_press(real device, real button)
您可以使用此函数从给定的游戏手柄插槽中模拟指定按钮的一次按下操作。按钮不会自动松开，如要松开，请使用 gamepad_button_release() 函数。
此函数不仅可以模拟指定按钮的一次按下操作，还可以模拟指定摇杆的一次偏离原点的操作。
如果成功执行操作，则返回 true，否则返回 false。

bool gamepad_button_release(real device, real button)
您可以使用此函数从给定的游戏手柄插槽中模拟指定按钮的一次松开操作。即使按钮未按下，也能执行此函数。
此函数不仅可以模拟指定按钮的一次松开操作，还可以模拟指定摇杆的一次回归原点的操作。
如果成功执行操作，则返回 true，否则返回 false。

bool gamepad_clear(real device)
此函数清除指定手柄插槽手柄的所有按键状态。
调用此函数后，函数 gamepad_button_check()、gamepad_button_check_pressed() 和 gamepad_button_check_released() 会受到影响，函数 gamepad_button_check_direct() 不会受到影响。
如果成功执行操作，则返回 true，否则返回 false。
