纹理

bool d3d_set_tex(real stage, real tex)
为指定的纹理阶段设置纹理，或使用 -1 取消绑定。可同时使用的最大纹理数量由 GPU 限制（通常为 8）。
注意： GM 每次绘制时都会覆盖纹理阶段 0。
举个例子，如果在 GML 中使用如下代码： 
d3d_set_tex(1, myTexture);  // 将指定纹理绑定到纹理阶段 1 中
那么就可以在着色器中通过 texld 或 texcrd 使用绑定的纹理： 
texld  r0, t0  // 当前正在绘制的纹理
texld  r1, t0  // 绑定到纹理阶段 1 中的纹理

// 或者使用 texcrd 获取纹理坐标
texcrd r0, t0
texcrd r1, t0
以此类推，将数据加载到 r0 会读取纹理阶段 0，r1 读取阶段 1，r2 读取阶段 2。即纹理阶段编号由目标寄存器号（r0 到 r5）确定。

bool d3d_set_tex_all(real tex)
为所有纹理阶段绑定相同的纹理，或使用 -1 取消绑定。

bool d3d_set_tex_int(real stage, real mode)
设置纹理阶段的插值模式。Stage 0 也可使用 texture_set_interpolation() 控制。
使用 tex_int_* 常量，默认值为 tex_int_nearest。

real d3d_set_tex_wrap(real stage, real xmode, real ymode)
设置纹理阶段的包裹模式，使用 tex_wrap_* 常量。类似于 texture_set_repeat()，但提供更多选项，并可分别控制 X/Y 方向。

bool d3d_set_tex_border(real stage, real col, real alpha)
设置 tex_wrap_border 模式的颜色。

这些函数用于处理一组设置。相比逐个设置参数，同时从一个配置文件中应用所有设置会更快。
real d3d_conf_tex_create()
创建新的纹理阶段配置。

bool d3d_conf_tex_set(real conf, real stage, real tex, real interp, real xmode, real ymode)
定义纹理阶段状态。

bool d3d_set_tex_conf(real conf)
从预定义的配置设置纹理阶段，仅修改已定义的阶段。
