字体

本扩展的字体功能基于 SDF（Signed Distance Field，有向距离场） 算法，常用于 TextMeshPro 等现代游戏引擎的字体渲染系统。其特点有：

  • 支持任意缩放字形和改变字形的粗细度（可精确到小数）。
  • 字体加载快，且纹理占用显存少（是普通纹理的 1/4）。
  • 支持描边、内/外发光、空心字体、柔和边缘的文字阴影等丰富的文字效果。
使用字体需要两个文件：字形的 SDF 纹理图片（通常是 png）和记录字形信息的 csv 文件。两者需由字体生成工具（如 tiny-sdf）预先制作。

字体的加载与释放

real sdf_add_font(string image_path, string csv_path)
加载一个 SDF 字体。参数 image_path 是字形纹理图片的路径，csv_path 是字形信息文件的路径。
返回新字体的 ID，失败时返回 -1。

bool sdf_delete_font(real id)
删除给定的字体并释放其资源。
如果成功执行操作，则返回 true，否则返回 false。

bool sdf_release_cache()
释放扩展内部缓存的排版结果。当字体或文字绘制参数经常变化时，调用此函数可以避免缓存占用过多内存。

当前字体与绘制参数

以下函数设置并查询“当前绘制字体”的各种参数，对之后的所有 SDF 文字绘制生效。

bool sdf_draw_set_font(real font_id)
设置当前绘制使用的字体。

real sdf_draw_get_font()
返回当前绘制使用的字体 ID。

bool sdf_draw_set_font_size(real size)
设置文字的缩放大小。该值最好与字形纹理的制作尺寸一致。

real sdf_draw_get_font_size()
返回当前的文字缩放大小。

bool sdf_draw_set_line_spacing(real spacing)
设置文字的行距（单位：像素）。默认值为 1。

real sdf_draw_get_line_spacing()
返回当前的行距。

bool sdf_draw_set_align_by_line(real by_line)
设置是否逐行对齐。默认值为 false，即整段文本作为一个整体进行水平对齐。
启用后，每一行都单独按其长度进行水平对齐。

bool sdf_draw_get_align_by_line()
返回当前是否启用了逐行对齐。

bool sdf_draw_set_use_shader(real use)
设置是否使用扩展内置的着色器绘制 SDF 文字。默认值为 true。
关闭后文字将直接使用顶点颜色绘制，可配合自定义着色器使用。

bool sdf_draw_get_use_shader()
返回当前是否使用扩展内置的着色器。

bool sdf_draw_set_premul(real premul)
设置是否使用预乘 Alpha 的绘制方式。启用后可以改善半透明文字的边缘效果。

bool sdf_draw_get_premul()
返回当前是否使用了预乘 Alpha 绘制。

bool sdf_draw_set_font_sharpness(real sharpness)
设置字体的锐度，即字形边缘的过渡宽度。该值最好与字形纹理的大小相同。

real sdf_draw_get_font_sharpness()
返回当前的字体锐度。

bool sdf_draw_set_font_thickness(real thickness)
设置字体的粗细度，取值范围为 100 至 900，默认值为 500。
小于 500 使字形变细，大于 500 使字形变粗，可精确到小数。

real sdf_draw_get_font_thickness()
返回当前的字体粗细度。

bool sdf_draw_set_text_gap(real gap)
设置字与字之间的间隔。

real sdf_draw_get_text_gap()
返回当前的文字间隔。

real draw_get_halign()
返回当前的水平对齐方式。此函数读取 GM8 中由 draw_set_halign() 设置的对齐值，SDF 文字绘制时同样遵循该设置。

real draw_get_valign()
返回当前的垂直对齐方式。此函数读取 GM8 中由 draw_set_valign() 设置的对齐值。

bool sdf_set_font_offset(real id, real xoffset, real yoffset)
为给定的字体设置绘制偏移量（单位：像素）。可用于修正字体的对齐位置。

字体配置（conf）

使用 sdf_draw_set_conf() 可以将一组字体参数保存为一个配置，之后用 sdf_apply_conf() 一键应用，方便在不同字体风格之间切换。

real sdf_draw_set_conf(real font, real size, real line_spacing, real sharpness, real thickness)
将给定的字体、缩放大小、行距、锐度和粗细度保存为一个字体配置。参数含义与对应的 sdf_draw_set_* 函数相同。
返回新配置的 ID，失败时返回 -1。

bool sdf_apply_conf(real conf_id)
应用给定的字体配置，将其中的字体和各项参数设为当前值。
如果成功执行操作，则返回 true，否则返回 false。

bool sdf_delete_conf(real conf_id)
删除给定的字体配置。

bool sdf_delete_all_conf()
删除所有字体配置。

文字测量

real sdf_string_width(string str)
返回给定字符串在当前字体下的宽度（单位：像素）。

real sdf_string_height(string str)
返回给定字符串在当前字体下的高度（单位：像素）。

real sdf_string_width_ext(string str, real w)
返回给定字符串在限定宽度 w 内自动换行后的宽度。

real sdf_string_height_ext(string str, real w)
返回给定字符串在限定宽度 w 内自动换行后的高度。

绘制文字

以下绘制函数默认使用当前的绘制字体和参数，颜色默认使用 GM 当前设置的绘制颜色（可通过 draw_set_color() / draw_set_alpha() 修改）。
所有函数都返回 true 表示成功。

bool sdf_draw_text(real x, real y, string str)
在坐标（x, y）处绘制文字。

bool sdf_draw_text_ext(real x, real y, string str, real w)
在坐标（x, y）处绘制文字，并在限定宽度 w 内自动换行。

bool sdf_draw_text_transformed(real x, real y, string str, real xscale, real yscale, real angle)
以指定的水平和垂直缩放、旋转角度（度）绘制文字。

bool sdf_draw_text_ext_transformed(real x, real y, string str, real w, real xscale, real yscale, real angle)
在限定宽度内换行，并同时应用缩放和旋转。

bool sdf_draw_text_color(real x, real y, string str, real c1, real c2, real c3, real c4, real alpha)
绘制文字并为文字的四个角分别指定颜色（GM 颜色）和整体透明度（0 至 1）。
参数 c1 至 c4 分别对应左上、右上、右下、左下。

bool sdf_draw_text_ext_color(real x, real y, string str, real w, real c1, real c2, real c3, real c4, real alpha)
在限定宽度内换行，并为文字四角分别指定颜色和透明度。

bool sdf_draw_text_transformed_color(real x, real y, string str, real xscale, real yscale, real angle, real c1, real c2, real c3, real c4, real alpha)
应用缩放和旋转，并为文字四角分别指定颜色和透明度。

bool sdf_draw_text_ext_transformed_color(real x, real y, string str, real w, real xscale, real yscale, real angle, real c1, real c2, real c3, real c4, real alpha)
同时应用换行、缩放、旋转和四角颜色，功能最完整的文字绘制函数。

bool sdf_draw_text_rich(real x, real y, string str, real xscale, real yscale)
在坐标（x, y）处绘制富文本，并以 xscale 和 yscale 缩放。字符串中可使用富文本标签，详细语法见 富文本 一节。
