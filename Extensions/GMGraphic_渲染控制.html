渲染控制

雾效

bool gpu_set_fog(real enable, real colour, real start, real end, [real mode], [real density])
设置雾效。参数 enable 控制雾效开关，colour 是雾的颜色（GM 颜色），start 和 end 是雾的起始和结束距离。
可选参数 mode 指定雾的类型：0 = 线性（默认，使用 start/end），1 = 指数，2 = 指数平方（后两者使用 density）。
可选参数 density 是指数雾的密度（0 至 1）。只传 4 个参数时自动按线性雾处理。

Z 测试与写入

bool gpu_set_zwriteenable(real enable)
设置是否写入 Z 缓冲区。

bool gpu_set_ztestenable(real enable)
设置是否启用 Z 测试。

bool gpu_set_ztestfunc(real func)
设置 Z 测试使用的比较函数。参数 func 使用 GM 的比较常量（例如 cmp_lessequal）。默认使用小于等于。
如果当前设备不支持 Z 测试，则返回 false。

Alpha 测试

bool gpu_set_alphatestenable(real enable)
设置是否启用 Alpha 测试。

bool gpu_set_alphatestref(real ref)
设置 Alpha 测试的参考值（0 至 255）。Alpha 值低于此值的像素不会被绘制。

bool gpu_set_alphatestfunc(real func)
设置 Alpha 测试使用的比较函数。参数 func 使用 GM 的比较常量（此功能为 D3D 扩展）。

颜色写入与深度偏移

bool gpu_set_color_mask(real enable, real r, real g, real b, real a)
设置颜色写掩码。参数 enable 是总开关，其余四个参数分别控制红、绿、蓝和 Alpha 通道是否可写入。
当 enable 关闭时，所有通道都不写入。如果当前设备不支持颜色写掩码，则返回 false。

bool gpu_set_depth(real depth)
设置深度偏移（Z-bias），用于防止具有相同坐标的几何体之间的 Z-fighting（例如无闪烁地叠加线框）。
参数 depth 为整数 0 至 16，默认值为 0。

bool gpu_set_fillmode(real mode)
设置多边形的填充模式。参数 mode 使用 D3D 填充模式常量：1 = 点填充，2 = 线框，3 = 实体（默认）。
点填充模式会遵循点图元设置。

bool gpu_set_normal_auto(real state)
设置是否自动归一化法线。启用后可以修复模型缩放时产生的光照问题。

点图元与点精灵

bool d3d_set_point_size(real size)
设置点图元的大小。可使用 d3d_dev_get_point_max_size() 查询设备支持的最大值。

bool d3d_set_point_size_min(real size)
设置点图元的最小大小（配合距离衰减使用）。

bool d3d_set_point_size_max(real size)
设置点图元的最大大小（配合距离衰减使用）。

bool d3d_set_point_scale(real state)
设置是否启用点图元的距离衰减。启用后点的大小会随到相机的距离变化，需要与 d3d_set_point_scale_coef() 配合。

bool d3d_set_point_scale_coef(real coef1, real coef2, real coef3)
设置点图元距离衰减公式的系数，默认值为（1, 0, 0）。
最终点的大小按照公式 size * sqrt(1 / (coef1 + coef2 * 距离 + coef3 * 距离的平方)) 计算。

bool d3d_set_point_sprite(real state)
设置是否启用点精灵。启用后可以为点图元应用纹理，配合 texture_set_stage() 使用。

扩展图元

扩展图元允许你在一个图元中绘制多达 8192 个顶点（GM8 自带的限制是 1024）。每个顶点可包含位置、法线、漫反射和镜面反射颜色/透明度，以及最多 8 个纹理坐标，配合顶点着色器可进行逐顶点计算。
使用 d3d_primitive_begin_ext() 开始，添加顶点后以 d3d_primitive_end_ext() 结束绘制；draw_* 版本是功能相同的 2D 简化版。

bool d3d_primitive_begin_ext(real primitive, real textured)
开始绘制一个扩展图元。参数 primitive 使用 GM 的图元类型常量（例如 pr_trianglelist），参数 textured 传 true 启用纹理坐标。

bool d3d_vertex_ext(real x, real y, real z, real nx, real ny, real nz, real col, real alpha, real speccol, real specalpha)
向扩展图元添加一个顶点。参数依次为顶点坐标（x, y, z）、法线（nx, ny, nz）、漫反射颜色（GM 颜色）、透明度（0 至 1）、镜面反射颜色和镜面反射透明度。

bool d3d_vertex_ext_tex(real stage, real xtex, real ytex)
为上一个添加的顶点指定纹理坐标。参数 stage 是纹理坐标集编号（0 至 7），xtex 和 ytex 是纹理坐标（0 至 1）。
每个顶点最多可指定 8 组纹理坐标。

bool d3d_vertex_ext_next()
结束当前顶点的定义并进入下一个顶点。

bool d3d_primitive_end_ext()
结束扩展图元的定义并提交绘制。

bool draw_primitive_begin_ext(real primitive, real textured)
d3d_primitive_begin_ext() 的 2D 版本，用法相同。

bool draw_vertex_ext(real x, real y, real col, real alpha, real speccol, real specalpha)
d3d_vertex_ext() 的 2D 版本。没有法线和 Z 坐标，其余参数相同。

bool draw_vertex_ext_tex(real stage, real xtex, real ytex)
d3d_vertex_ext_tex() 的 2D 版本，用法相同。

bool draw_vertex_ext_next()
结束当前顶点的定义并进入下一个顶点（2D 版本）。

bool draw_primitive_end_ext()
结束扩展图元的定义并提交绘制（2D 版本）。
