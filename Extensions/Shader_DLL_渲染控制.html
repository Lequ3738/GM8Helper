渲染控制

bool d3d_set_mask(bool r, bool g, bool b, bool a)
独立启用/禁用各个颜色通道的写入。例如，在表面绘制时不影响 Alpha 通道。

bool d3d_set_zwrite(bool state)
启用/禁用深度缓冲区写入，类似于上个函数但用于深度。

bool d3d_set_zbias(real bias)
偏移绘制深度，防止同位置多边形的深度冲突导致闪烁问题，适用于阴影、贴花等。
值越高，物体越靠前。传入整数 0-16，默认 0（禁用）。

bool d3d_set_alphatest(real value, real mode)
通过 Alpha 测试过滤像素，可以提高性能。value 范围为 0-255，mode 使用 cmp_* 常量。传入 -1 以禁用 Alpha 测试，正值启用。
例如：

d3d_set_alphatest(128, cmp_greaterequal);
仅绘制不透明度至少为 50% 的像素，提高性能。

bool d3d_set_ztest(real mode)
仅绘制符合深度测试条件的像素，与当前深度缓冲区值比较。使用 cmp_* 常量，默认 cmp_lessequal。

bool d3d_set_fillmode(real mode)
选择渲染模式（点、线框、填充）。使用 fillmode_* 常量，默认 fillmode_solid。

bool d3d_set_normal_auto(bool state)
启用/禁用自动法线归一化，解决缩放后模型光照异常问题。
