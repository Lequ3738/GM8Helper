信息和配置

bool gamepad_is_supported(real device)
返回此扩展是否支持指定的手柄。
参数 device 是手柄被分配的指定插槽索引。
若此函数返回 false，则不支持此插槽的手柄。意味着在使用 gamepad_button_check() 之类的输入函数时，不能使用 gp_face1、gp_axisrh 之类的输入常量。只能使用原始索引和原始索引偏移常量来进行使用。

real gamepad_get_device_count()
返回已经连接到设备的手柄数量。

string gamepad_get_description(real device)
返回一个包含给定游戏手柄描述的字符串。
例如，PS3 手柄可能会返回类似于“PLAYSTATION(R)3 Controller”的字符串，而 Xbox 360 手柄可能会返回“Xbox 360 Controller (XInput STANDARD GAMEPAD)”的字符串。该字符串与硬件相关，返回的值将取决于指定插槽索引的游戏手柄。
如果插槽索引不存在，则返回“no gamepad”字符串。

通过此函数，可以方便地为不同类型的手柄实现不同的功能，或是绘制不同的图标。

string gamepad_get_guid(real device)
返回指定插槽索引的游戏手柄的 GUID。该函数返回以下字符串之一：

  • 如果没有可用的 GUID，则返回“none”
  • 如果游戏手柄插槽索引超出范围，则返回“device index out of range”
  • 如果插槽分配了游戏手柄并且可以获取它的 GUID，则返回 GUID 字符串，类似于“050000005e040000fd020000ffff3f00”
此函数通常与 gamepad_get_description() 结合使用，以生成重新映射控制器所需的部分 SDL 字符串。

real gamepad_get_id(real device)
返回指定插槽索引的游戏手柄的实例 ID。
此函数专为多手柄连接而设计。当有多个手柄连接时，直接记录插槽索引并不可靠。当发生游戏手柄插入设备（或将其移除）的情况时，插槽索引对应的手柄设备可能会改变。
此函数返回的实例 ID 在游戏运行期间，该手柄设备自插入到拔出时都不会改变。

real gamepad_get_axis_deadzone(real device)
此函数可用于获取操纵杆轴的“死区”值。您指定要获取的设备插槽，该函数将返回一个介于 0 到 1 之间的值，该值反映了操纵杆轴被视为处于 0 位置的阈值。
默认死区为 0.05。

real gamepad_get_inputs_index(real device, real constant)
此函数可用于获取受支持手柄的输入常量所绑定的原始按钮/轴值。
如果获取的是不受支持的手柄，或是手柄不存在，则输出 -1。

bool gamepad_set_vibration(real device, real left_motor, real right_motor, real time)
使用此函数，您可以设置游戏手柄电机的振动，任一电机使用从 0（无振动）到 1（完全振动）的值。
参数 left_motor 是设置左电机（通常是低频电机）的振动量。
参数 right_motor 是设置右电机（通常是高频电机）的振动量。
参数 time 是设置电机的振动时间，单位为秒。
此函数通常返回 true，若返回 false，则说明手柄不支持电机振动。

bool gamepad_set_color(real device, real color)
此函数可用于设置 PlayStation 控制器内 LED 灯的颜色。您需要指定要设置的设备插槽，然后指定一个颜色，该颜色可以是任何颜色常量，或是使用特定颜色函数创建的颜色值，或是十六进制值（如$FFFFFF）。
如果成功执行操作，则返回 true，否则返回 false。

bool gamepad_set_axis_deadzone(real device, real deadzone)
此功能可用于设置操纵杆轴的“死区”。您指定要设置的设备插槽，然后设置一个 0 到 1 之间的值，如果输入量低于给定值，则认为操纵杆轴处于 0 位置。请注意，这是一个全局设置，将影响指定设备插槽上连接的所有操纵杆的所有轴。
使用此函数并不意味着轴值将从死区值开始，因为 gamepad_axis_value() 函数将始终返回一个介于 -1 和 0 之间或 0 和 1 之间的归一化值。例如，将死区设置为 0.2 意味着，当原始轴值超过 0.2 时，向右推动摇杆才会开始返回 0 到 1 之间的值——因此，当原始值为 0.2 时，返回值将为 0；当原始值为 0.5 时，返回值将为 0.375；或者，如果原始值为 0.9，则返回值将为 0.875。
如果成功执行操作，则返回 true，否则返回 false。

real gamepad_axis_count(real device)
此功能将返回被检查设备上的“摇杆”控件的数量。

real gamepad_button_count(real device)
此功能将返回被检查设备上的“按钮”控件的数量。

real gamepad_hat_count(real device)
此功能将返回被检查设备上的“十字键”控件的数量。
