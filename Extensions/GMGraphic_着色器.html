着色器

创建与销毁着色器

real shader_create_asm(string vs, string ps)
根据给定的着色器源代码创建着色器（返回着色器 ID）。此函数同时适用于 D3D8 和 D3D9 后端。
参数 vs 和 ps 分别是顶点着色器和像素着色器的汇编源码字符串。将某个参数设为空字符串表示不使用该阶段（即该阶段为透传）。
如果两个参数都为空字符串，则返回 -1。
着色器创建的详细要求请参考汇编着色器部分的说明。

real shader_create(string src, [string vs_entry], [string ps_entry])
从一个 HLSL 源码文件创建着色器。仅适用于 D3D9 后端（在 D3D8 下返回 -1）。
参数 src 是 HLSL 源码字符串，源码中同时包含顶点着色器和像素着色器的入口函数。
可选参数 vs_entry 和 ps_entry 分别是顶点着色器和像素着色器的入口函数名，设为空字符串时使用默认入口名 mainVS 和 mainPS。
如果源码中没有对应的入口函数，则该阶段为透传。

bool shader_destroy(real sh)
销毁给定的着色器并释放其资源（包括顶点/像素着色器对象、常量表和该着色器的 uniform 条目）。
如果成功执行操作，则返回 true，否则返回 false。

绑定与切换着色器

bool shader_set(real sh)
绑定给定的着色器，之后绘制的图形都会应用此着色器。绑定时会自动应用着色器的默认常量（仅限 HLSL 常量表）。
如果成功执行操作，则返回 true，否则返回 false。

bool shader_reset()
解除当前绑定的着色器，恢复默认的固定管线绘制。此函数等价于 shader_set(-1)。
在每一帧的绘制结束时，通常需要调用此函数来复位着色器。

real shader_current()
返回当前绑定的着色器 ID，如果没有绑定任何着色器则返回 -1。

Uniform 参数

uniform 是着色器中的可调参数。首先使用 shader_get_uniform() 获取参数句柄，再使用 shader_set_uniform_* 系列函数写入数值。
对于汇编着色器，uniform 通过寄存器数字串指定（例如 "0"、"ps.0"、"vs.3"）；对于 HLSL 着色器，通过常量名指定（例如 "uColor"、"ps.uColor"、"vs.uWVP"）。前缀 ps. / vs. 用于指定阶段，不区分大小写。

real shader_get_uniform(real sh, string uni)
获取给定着色器中指定 uniform 的句柄。找不到该参数时返回 -1。

bool shader_has_uniform(real sh, string uni)
检测给定的着色器是否含有指定名称的 uniform。仅适用于 D3D9 后端（依赖 HLSL 常量表，D3D8 下始终返回 false）。

real shader_get_sampler_index(real sh, string uni)
获取给定着色器中指定采样器的索引（纹理阶段编号）。需配合 texture_set_stage() 将纹理绑定到该阶段。找不到时返回 -1。

bool shader_set_uniform_f(real h, real x, [real y], [real z], [real w])
为指定的 uniform 句柄写入 1 至 4 个浮点数。少传的参数会自动补 0。
例如要写入一个 float4 类型的参数，需要提供 4 个值；只写一个 float 类型的参数时传 1 个值即可。
如果成功执行操作，则返回 true，否则返回 -1。

bool shader_set_uniform_i(real h, real x, [real y], [real z], [real w])
为指定的 uniform 句柄写入整数（int）参数。用法与 shader_set_uniform_f() 相同。
如果成功执行操作，则返回 true，否则返回 -1。

bool shader_set_uniform_b(real h, real x, [real y], [real z], [real w])
为指定的 uniform 句柄写入布尔（bool）参数。传入的值非 0 会被转换为 1，为 0 则转换为 0。
用法与 shader_set_uniform_f() 相同。

bool shader_set_uniform_color(real h, real col, real alpha)
为指定的 uniform 句柄写入一个颜色参数。参数 col 使用 GM 的颜色常量，函数会自动将其拆分为红、绿、蓝分量，并和 alpha 一起写入。
如果成功执行操作，则返回 true，否则返回 -1。

bool shader_set_uniform_matrix(real h, real mtx_type, real size)
为指定的 uniform 句柄写入一个矩阵参数。参数 mtx_type 指定要写入哪个矩阵：1 = 世界矩阵，2 = 视图矩阵，4 = 投影矩阵，7 = 世界-视图-投影（WVP）组合矩阵。
参数 size 指定要写入的寄存器数量，通常为 4（完整的 4x4 矩阵）；传入 0 或小于 1 的值时按 4 处理。
如果成功执行操作，则返回 true，否则返回 -1。

采样器

使用 texture_set_stage() 将纹理绑定到着色器的采样器阶段，再使用 gpu_set_tex*_ext 系列函数控制该阶段的纹理参数。

bool texture_set_stage(real sampler, real tex)
将纹理绑定到指定的采样器阶段。参数 sampler 是采样器索引，参数 tex 是纹理 ID。传入负数 tex 可清空该阶段的纹理。
如果成功执行操作，则返回 true，否则返回 false。

bool gpu_set_texfilter_ext(real sampler, real filter)
设置指定采样器阶段的纹理过滤方式。参数 filter：0 = 最近邻（point），1 = 线性（linear），2 = 各向异性（anisotropic），3 = 不采样。

bool gpu_set_texrepeat_ext(real sampler, real h, real v, [real bcol])
设置指定采样器阶段的纹理寻址方式。参数 h 和 v 分别控制水平和垂直方向，传 0 表示夹取（clamp），传其他值则作为 D3D 寻址常量传入。
可选参数 bcol 是边框寻址模式使用的颜色（GM 颜色）。

bool gpu_set_tex_max_aniso_ext(real sampler, real aniso)
设置指定采样器阶段的最大各向异性等级。参数 aniso 取值为 1、2、4、8 或 16，其中 1 表示关闭各向异性过滤。

bool gpu_set_tex_mip_filter_ext(real sampler, real filter)
设置指定采样器阶段的 Mip 过滤方式。参数 filter：0 = 无 Mip 过滤，1 = 最近邻（point），3 = 线性（linear）。

bool gpu_set_tex_border_ext(real sampler, real col, real alpha)
设置指定采样器阶段在边框寻址模式下使用的边框颜色。参数 col 是 GM 颜色，alpha 是透明度（0 至 1）。
