顶点着色器

此扩展支持顶点着色器版本 1.1（vs.1.1），它可以对顶点进行一系列操作，包括矩阵变换，光照和法线计算等。

顶点着色器只能作用于扩展图元相关的函数，对 GM 中的绘制函数不起作用（比如，你不能将 vs 着色器作用于 draw_sprite() 等类似的函数上）。

可用函数

real d3d_vs_create(string assembly)
从汇编源代码编译顶点着色器，返回索引以用于其他函数。

bool d3d_vs_destroy(real shader)
释放着色器使用的内存，并销毁着色器。

bool d3d_set_vs(real shader)
设置当前顶点着色器，或使用 -1 表示不使用任何着色器。
GM 的默认渲染功能不会受影响，但对于扩展图元函数，此着色器将完全取代变换、光照、颜色和纹理计算。

bool d3d_set_vs_const(real constant, real x, real y, real z, real w)
设置顶点着色器常量寄存器，可用96 个 4 分量寄存器。

bool d3d_set_vs_const_col(real shader, real col, real alpha)
设置 GM 格式的颜色到顶点着色器常量寄存器。是一个便捷的方式。

bool d3d_set_vs_const_matrix(real constant)
将转置的 世界 × 视图 × 投影矩阵（world × view × projection matrix） 赋值到 4 个常量寄存器。
然后你可以在着色器中使用 m4x4 oPos, v0, cn 来转换顶点，使其符合 GM 的默认行为。例如：

  • 0 会设置 c0, c1, c2, c3
  • 4 会设置 c4, c5, c6, c7
注意： 如果你使用 d3d_transform 相关函数，请确保在这些函数之后调用本函数，否则变换结果会出错。
这些函数用于处理一组设置。相比逐个设置参数，同时从一个配置文件中应用所有设置会更快。
real d3d_conf_vs_create()
创建新的顶点着色器配置，并返回其索引。

bool d3d_conf_vs_set(real conf, real constant, real x, real y, real z, real w)
定义顶点着色器常量状态。

bool d3d_set_ps_conf(real conf)
从预定义配置中设置顶点着色器常量。未设置的值不会覆盖当前值。相比单独指定设置，此方法速度更快。

编写顶点着色器

在着色器模型 1.4 (Shader Model 1.4) 中，顶点着色器同样是用汇编语言编写。不过它的指令数限制没有像素着色器那么严格，最多可以执行128条指令。

顶点着色器针对每个顶点都会执行一次。

下面的顶点着色器模拟正常的变换/颜色/纹理设置：

vs.1.1             // 声明着色器版本，所有着色器都必须包含此声明。

m4x4 oPos,  v0,c0  // 位置，由 c0-c3 中的矩阵变换

mov  oD0,   v5     // 漫反射颜色，是PS着色器中的 v0
mov  oD1,   v6     // 镜面颜色，是PS着色器中的 v1

mov  oT0,   v7     // 纹理坐标，是PS着色器中的 t0-t5，oT6和oT7在PS着色器中不可用
mov  oT1,   v8
mov  oT2,   v9
mov  oT3,   v10
mov  oT4,   v11
mov  oT5,   v12
mov  oT6,   v13
mov  oT7,   v14
