像素着色器

正如你在演示中所看到的，着色器非常快速且灵活。你可以执行色调映射、颜色控制、折射、模糊等许多高级技术。

此扩展支持着色器模型 1.4（ps.1.4）。虽然相较于新版本，它的功能较为有限，但兼容性极高，且仍然比 GM 默认的光栅效果功能强大得多。作为一个2001年的标准，它的优势在于：几乎所有 GPU 都支持它，甚至是你那台笔记本里糟糕的 Intel GMA950 也能运行它。

可用函数

real d3d_ps_create(string assembly)
从汇编代码编译像素着色器，返回索引，供其他 shader 函数使用。

bool d3d_ps_destroy(real shader)
释放着色器使用的内存，并销毁着色器。

bool d3d_set_ps(real shader)
设置当前像素着色器，或使用 -1 表示不使用任何着色器。
着色器的工作方式类似于混合模式：一次只能启用一个，可开启或关闭。着色处理在绘制雾效和 Alpha 测试之前进行。

bool d3d_set_ps_const(real constant, real r, real g, real b, real a)
设置像素着色器常量寄存器。
共有 8 个寄存器，索引范围为 0-7，每个寄存器包含 4 个值，取值范围为 -1 到 1。等同于在着色器汇编中使用 "def" 指令。

bool d3d_set_ps_const_col(real shader, real col, real alpha)
设置 GM 格式的颜色到像素着色器常量寄存器。是一个便捷的方式。

这些函数用于处理一组设置。相比逐个设置参数，同时从一个配置文件中应用所有设置会更快。
real d3d_conf_ps_create()
创建新的像素着色器配置，并返回其索引。

bool d3d_conf_ps_set(real conf, real constant, real r, real g, real b, real a)
定义像素着色器常量状态。

bool d3d_set_ps_conf(real conf)
从预定义配置中设置像素着色器常量。未设置的值不会覆盖当前值。相比单独指定设置，此方法速度更快。

编写像素着色器

着色器是用汇编语言编写的。我不会在这里详细讲解每个指令，但会给你一个整体概述。

着色器具有用于存储数据的寄存器，以及对其执行各种操作的指令。寄存器类似于变量，而指令类似于函数。每个寄存器包含四个值，这些值可以表示 RGBA 颜色、纹理坐标或任何你想要的数据。

像素着色器在绘制每个像素时都会执行一次。

下面是一个简单的着色器，它的输出与普通绘图相同：

ps.1.4           // 声明着色器版本，所有着色器都必须包含此声明。

texld r0, t0     // 读取纹理阶段 0 的 t0 坐标。
mul   r0, r0,v0  // 纹理颜色乘以绘图颜色，并将结果存储到 r0。

这个着色器会将纹理的 Alpha 值减半，不受 image_blend/image_alpha 影响： 

ps.1.4

def   c0, 1,1,1,0.5  // 定义常量寄存器。
texld r0, t0 
mul   r0, r0,c0      // 将常量寄存器乘以纹理颜色。
要查看更多复杂且有用的示例，请参考演示 GMK 文件。多多尝试不同的修改，这样比单纯阅读文档能学到更多东西。
