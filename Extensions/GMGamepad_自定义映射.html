自定义映射

string gamepad_get_mapping(real device)
此函数可用于获取指定插槽手柄的映射字符串。返回的字符串有如下可能：
  • 游戏手柄的当前映射字符串，例如：
    "050000005e040000fd020000ffff3f00,Xbox Wireless Controller,a:b0,b:b1,start:b4,dpdown:h0.4,dpleft:h0.8,dpright:h0.2,dpup:h0.1,guide:b6,leftshoulder:b9,leftstick:b7,lefttrigger:a4,leftx:a0,lefty:a1,rightshoulder:b10,rightstick:b8,righttrigger:a5,rightx:a2,righty:a3,x:b2,y:b3,platform:windows"
  • 如果没有可用的映射，则为“no mapping”字符串。
  • 如果插槽索引不是有效的游戏手柄索引，则为“device index out of range”字符串。

bool gamepad_test_mapping(real device, string mapping)
此函数用于设置游戏手柄映射。您提供要设置的游戏手柄的插槽索引，然后提供映射字符串，该字符串应使用 SDL 格式创建，其中包含以下字段：

<guid>,<description>,platform:<platform-name>,<bindings>
每个字段中应包含的详细信息包括：
  • guid - 唯一标识设备类型的数字和字母字符串（可以使用 gamepad_get_guid() 函数获得）
  • description - 设备的 ASCII 描述（可以使用 gamepad_get_description() 函数获得）
  • platform-name - 为“platform:windows”
  • bindings - 一组以 ',' 分隔的条目，用于将实际输入绑定到特定的输入常量
以逗号分隔的条目列表遵循每个条目的特定格式： 
<abstract-gp-name>:<value-binding>
此处 <value-binding>（即：直接游戏手柄输入）可以是以下任何一项：
  • a<N> - 这表示手柄的一个从索引 0 到 gamepad_axis_count() - 1 的摇杆
  • b<N> - 这表示手柄的一个从索引 0 到 gamepad_button_count() - 1 的按钮
  • h<N>.<mask> - 这表示手柄的一个从索引 0 到 gamepad_hat_count() - 1 的十字键，<mask> 为 1、2、4 或 8
每个输入值都应绑定到一个 SDL 名称，该名称表示为 <abstract-gp-name>，而该名称又绑定到一个输入常量。下表显示了 SDL 名称和输入常量之间的等效性： 构建映射字符串后，它应该类似于如下字符串： 
"050000005e040000fd020000ffff3f00,Xbox Wireless Controller,a:b0,b:b1,start:b4,dpdown:h0.4,dpleft:h0.8,dpright:h0.2,dpup:h0.1,guide:b6,leftshoulder:b9,leftstick:b7,lefttrigger:a4,leftx:a0,lefty:a1,rightshoulder:b10,rightstick:b8,righttrigger:a5,rightx:a2,righty:a3,x:b2,y:b3,platform:windows"
如果成功执行操作，则返回 true，否则返回 false。

bool gamepad_remove_mapping(real device)
此函数可用于从给定的游戏手柄插槽索引中删除当前设备映射。
调用后，如果您希望能够使用游戏手柄常量正确检测输入，则需要使用 gamepad_test_mapping() 函数重新映射插槽索引。
如果成功执行操作，则返回 true，否则返回 false。
