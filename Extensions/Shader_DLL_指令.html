指令

算术运算指令：

可以使用临时寄存器、常量寄存器或颜色寄存器作为参数。

mov rn, src
最基本的指令，将 src 复制到 rn。

add rn, src1, src2
将 src1 和 src2 相加，并存储到 rn。

sub rn, src1, src2
计算 src1 - src2，并存储到 rn。

mul rn, src1, src2
计算 src1 × src2，并存储到 rn。

mad rn, src1, src2, src3
先计算 src1 × src2，再加上 src3。

lrp rn, src1, src2, src3
线性插值计算 (src2 + ((src3 - src2) × src1))。

cnd rn, src1, src2, src3
如果 src1 > 0.5，则 rn = src2，否则 rn = src3。

cmp rn, src1, src2, src3
如果 src1 >= 0，则 rn = src2，否则 rn = src3。

dp3 rn, src1, src2
计算 RGB 颜色的点积 (src1.r × src2.r) + (src1.g × src2.g) + (src1.b × src2.b)，并将结果存储到 rn 的所有分量。

dp4 rn, src1, src2
与 dp3 类似，但计算四个分量的点积。

bem rn.rg, src1, src2
应用假凹凸环境贴图转换。此指令占用2个指令槽。
此指令执行以下计算： 

(Given n == dest register #)
rn.r = src1.r + D3DTSS_BUMPENVMAT00(stage n) * src2.r 
                + D3DTSS_BUMPENVMAT10(stage n) * src2.g

rn.g = src1.g + D3DTSS_BUMPENVMAT01(stage n) * src2.r
                + D3DTSS_BUMPENVMAT11(stage n) * src2.g

使用此指令的规则与限制：

  • 此指令必须出现在着色器的第一阶段（即相位标记之前）。
  • 每个着色器只允许使用此指令一次。
  • 除了目标寄存器写入掩码为 .rg 的限制外，源 src1, src2 和指令上的修饰符不受约束。
  • 此指令不可共发。

纹理指令：

texld rn, tn
从 tn 坐标读取当前纹理阶段的颜色数据，并将结果存储到 rn。
将数据加载到 r0 会读取纹理阶段 0，r1 读取阶段 1，r2 读取阶段 2，依此类推。即纹理阶段编号由目标寄存器号（r0 到 r5）确定。
r0, t0 是 GM 当前正在绘制的纹理，可以是表面（surface）、精灵（sprite）、背景（background）等。
在 阶段 2（phase 2）中，你可以使用 rn 作为坐标。

texcrd rn, tn
与 texld 类似，但它复制纹理坐标，而不是读取纹理颜色。
使用此指令时，你必须添加 .rgb 目标写掩码（destination writemask）（见下文）。

texkill tn
如果 tn 的任何 RGB 分量 小于 0，则阻止该像素被绘制。
在 阶段 2 中，你可以使用 rn 作为坐标。

texdepth r5
计算该像素 深度缓冲区（z-buffer） 对比测试中使用的深度值。
该指令在该像素的深度缓冲区比较测试中使用 r5.r / r5.g。 r5.b 和 r5.a 中的数据将被忽略。 如果 r5.g = 0，则 r5.r / r5.g = 1.0。
临时寄存器 r5 是此指令唯一可以使用的寄存器。执行此指令后，临时寄存器 r5 在着色器中不可用。


阶段指令：

phase
此指令标志着阶段 1 和阶段 2 之间的过渡。如果不存在阶段指令，则整个着色器将像阶段 2 着色器一样运行。
在阶段 2 中，你只能访问 vn 寄存器，并且 rn 只能用作纹理坐标。
执行 phase 指令后，所有 rn 寄存器的 Alpha 通道都会被清空。


指令修饰符：

可以通过添加修饰符来修改算术指令的结果。

_x2, _x4, _x8
将结果乘以 2、4 或 8。

_d2, _d4, _d8
将结果除以 2、4 或 8。

_sat
将结果限制在 [0,1] 之间。
例如，add_x2_sat 先加法计算，再乘以 2，并将结果限制在 [0,1]。


临时寄存器修饰符：

如果输入来自临时寄存器，你可以使用以下修饰符来修改输入值。
（这些修饰符不会改变原寄存器的值，只影响计算结果。）

rn_bias
从输入值中减去 0.5。

1-rn
取反输入值（1 - rn）。

-rn
取负输入值。

rn_x2
将输入值乘以 2。

rn_bx2
先减去 0.5，然后乘以 2。
（此修饰符可用于将 [0, 1] 范围的数据转换为 [-1, 1]。）
