纹理图集

纹理图集（Texture Atlas）将多张图片打包进一张大纹理，绘制时通过不同的纹理坐标采样，从而把多次绘制调用合并为一次，大幅减少 DrawCall 开销。
图集支持三种来源的图片：文件（仅支持 gmspr 和 png 格式）、GM 的 Sprite 和 GM 的 Background。
为与 GM8 内部资源 ID 区分，图集内的图片（Image）ID 从 100,000 开始计数，纹理（Texture）ID 从 1,000,000 开始计数。

手动创建图集

real texture_atlas_create(real size)
创建一个新的纹理图集。参数 size 是图集的边长，取值为 256、512、1024 或 2048。
返回新图集的 ID，失败时返回 -1。

bool texture_atlas_delete(real id)
删除给定的纹理图集并释放其资源。
如果成功执行操作，则返回 true，否则返回 false。

real texture_atlas_add_file(real id, string file)
向给定的图集中添加一个图像文件（仅支持 gmspr 和 png 格式）。
返回该图片在图集中的 Image ID，失败时返回 -1。

real texture_atlas_add_sprite(real id, real spr)
向给定的图集中添加一个已导入 GM 的 Sprite。添加后不会自动删除该 Sprite，如需删除请调用 GM 的 sprite_delete()。
返回该图片在图集中的 Image ID，失败时返回 -1。

real texture_atlas_add_background(real id, real back)
向给定的图集中添加一个已导入 GM 的 Background。添加后不会自动删除该 Background，如需删除请调用 GM 的 background_delete()。
返回该图片在图集中的 Image ID，失败时返回 -1。

bool texture_atlas_burn(real id, real del_memdata)
将图集中的图片打包并上传至 GPU，生成最终的图集纹理。
参数 del_memdata 传 true 时，上传后删除内存中的图片数据，使图集变为只读（此后不能再向图集添加图片）。
图集在绘制之前必须先调用此函数。

bool texture_atlas_save(real id, string file_path)
将图集保存到文件（需先调用 texture_atlas_burn()）。参数 file_path 不含扩展名，保存时会生成对应的 png 图片文件。
保存的文件可配合 texture_atlas_load() 再次加载。

real texture_atlas_load(string file_path)
从文件加载之前保存的纹理图集，加载后图集为只读模式。
返回一个 GM ds_map，其中键 /Result/ 对应图集 ID，其余键为图片名称，对应各图片的 Image ID。失败时返回 -1。

自动打包模式

无需手动创建图集。调用 texture_atlas_auto_start() 开启自动模式，之后使用 texture_atlas_auto_add_*() 添加的图片会自动放入一个边长为 1024 的图集中，最后调用 texture_atlas_auto_finish() 打包所有图集。

bool texture_atlas_auto_start()
开启自动打包模式。

real texture_atlas_auto_add_file(string file)
在自动模式下添加一个图像文件。若现有的图集能放下该图片则直接放入，否则新建一个图集。
返回该图片在图集中的 Image ID，失败时返回 -1。

real texture_atlas_auto_add_sprite(real spr)
在自动模式下添加一个已导入 GM 的 Sprite。
返回该图片在图集中的 Image ID，失败时返回 -1。

real texture_atlas_auto_add_background(real back)
在自动模式下添加一个已导入 GM 的 Background。
返回该图片在图集中的 Image ID，失败时返回 -1。

real texture_atlas_auto_finish(real dont_twice)
结束自动打包模式，打包（上传）自动模式下创建的图集。
参数 dont_twice 传 true 时，已上传过的图集不会重复打包。
返回值：如果自动模式中新建了图集，返回一个包含所有图集 ID 的 GM ds_list；如果没有新建图集则返回 -2。

图集与图片查询

real texture_atlas_count()
返回当前图集的总数量。

bool texture_atlas_exists(real id)
检测给定的图集是否存在。

real texture_atlas_find_first()
返回第一个图集的 ID。可配合 texture_atlas_find_next() 遍历所有图集。

real texture_atlas_find_next(real id)
返回给定图集之后的下一个图集 ID。

real texture_atlas_find_last()
返回最后一个图集的 ID。

real texture_atlas_get_image_count(real atlas_id)
返回给定图集中图片的总数量。

real image_get_texture_atlas(real image_id)
返回给定 Image ID 所在的图集 ID。

real texture_atlas_get_image(real atlas_id, real pos)
返回给定图集中指定位置（0 起）的图片的 Image ID。

real texture_get_image(real texture_id)
返回给定 Texture ID 所属的图片的 Image ID。

real sprite_get_texture(real spr, real subimg)
返回给定 Sprite 中指定子图像的 Texture ID（图集扩展版，覆盖 GM8 内置同名函数）。传入已加入图集的 Sprite 时返回图集内的 Texture ID。

real background_get_texture(real back)
返回给定 Background 的 Texture ID（图集扩展版，覆盖 GM8 内置同名函数）。传入已加入图集的 Background 时返回图集内的 Texture ID。

real sprite_get_width(real id)
返回给定 Sprite 的宽度（图集扩展版，覆盖 GM8 内置同名函数）。传入图集 Image ID 时返回图集图片的宽度。

real sprite_get_height(real id)
返回给定 Sprite 的高度（图集扩展版，覆盖 GM8 内置同名函数）。传入图集 Image ID 时返回图集图片的高度。

real background_get_width(real id)
返回给定 Background 的宽度（图集扩展版，覆盖 GM8 内置同名函数）。传入图集 Image ID 时返回图集图片的宽度。

real background_get_height(real id)
返回给定 Background 的高度（图集扩展版，覆盖 GM8 内置同名函数）。传入图集 Image ID 时返回图集图片的高度。

real texture_get_width(real id)
返回给定 Texture ID 的宽度（图集扩展版，覆盖 GM8 内置同名函数）。

real texture_get_height(real id)
返回给定 Texture ID 的高度（图集扩展版，覆盖 GM8 内置同名函数）。

real texture_get_atlas_x(real id)
返回给定 Texture ID 在其图集纹理中的 X 坐标。

real texture_get_atlas_y(real id)
返回给定 Texture ID 在其图集纹理中的 Y 坐标。

bool image_in_atlas(real id)
判断给定的 ID 是否为图集内的 Image ID（即 ID 大于等于 100,000）。

bool texture_in_atlas(real id)
判断给定的 ID 是否为图集内的虚拟纹理 ID（即 ID 大于等于 1,000,000）。

图集配置

bool texture_atlas_set_crop(real crop)
设置是否启用图片的自动裁剪。启用后，加入图集的图片会自动裁剪掉四周的空白像素，减少图集占用空间。
该设置在所有图集上生效。

bool texture_atlas_get_crop()
返回当前是否启用了图片自动裁剪。

bool texture_atlas_set_amplificate(real ampl)
设置是否按照“边缘像素重复”的方式将图片加入图集。启用后，图片加入图集时会扩展一圈边缘像素，避免绘制时出现纹理边缘的渗色（bleeding）。
该设置在所有图集上生效。

bool texture_atlas_get_amplificate()
返回当前是否启用了边缘像素重复。
