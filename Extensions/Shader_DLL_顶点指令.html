指令

算术运算指令：

mov rn, src
最基本的指令，将 src 复制到 rn。

add rn, src1, src2
将 src1 和 src2 相加，并存储到 rn。

sub rn, src1, src2
计算 src1 - src2，并存储到 rn。

mul rn, src1, src2
计算 src1 × src2，并存储到 rn。

mad rn, src1, src2, src3
先计算 src1 × src2，再加上 src3。

lrp rn, src1, src2, src3
线性插值计算 (src2 + ((src3 - src2) × src1))。

dp3 rn, src1, src2
计算 RGB 颜色的点积 (src1.r × src2.r) + (src1.g × src2.g) + (src1.b × src2.b)，并将结果存储到 rn 的所有分量。

dp4 rn, src1, src2
与 dp3 类似，但计算四个分量的点积。

m3x2 rn, src1, src2
将 3 分量向量乘以 3x2 矩阵。此指令占用 2 个指令槽。
rn 是目标寄存器。结果是一个 2 分量向量。
src1 是表示 3 分量向量的源寄存器。
src2 是表示 3x2 矩阵的源寄存器，对应于 2 个连续寄存器中的第一个。 

m3x2   r0.xy, r1, c0   它相当于:

dp3   r0.x, r1, c0
dp3   r0.y, r1, c1
m3x3 rn, src1, src2
将 3 分量向量乘以 3x3 矩阵。此指令占用 3 个指令槽。
rn 是目标寄存器。结果是一个 3 分量向量。
src1 是表示 3 分量向量的源寄存器。
src2 是表示 3x3 矩阵的源寄存器，对应于 3 个连续寄存器中的第一个。 
m3x2   r0.xyz, r1, c0   它相当于:

dp3   r0.x, r1, c0
dp3   r0.y, r1, c1
dp3   r0.z, r1, c2
m3x4 rn, src1, src2
将 3 分量向量乘以 3x4 矩阵。此指令占用 4 个指令槽。

m4x3 rn, src1, src2
将 4 分量向量乘以 4x3 矩阵。此指令占用 3 个指令槽。

m4x4 rn, src1, src2
将 4 分量向量乘以 4x4 矩阵。此指令占用 4 个指令槽。

dst rn, src1, src2
计算距离向量。以下代码片段显示了执行的作用： 

rn.x = 1;
rn.y = src1.y * src2.y;
rn.z = src1.z;
rn.w = src2.w;
exp rn, src
计算全精度指数。此指令占用 10 个指令槽。
src 必须显式指定一个分量（如.x, .y, .z, .w或其等效的.r, .g, .b, .a）。
以下代码片段显示了执行的作用： 
rn = power(2, src.x)
expp rn, src
计算部分精度指数。

frc rn, src
返回 src 的小数部分。此指令占用 3 个指令槽。

lit rn, src
通过计算两个点积和一个指数的照明系数，提供对照明的部分支持。
假定源向量包含以下伪代码中显示的值： 

src.x = N*L        // 法线与光照方向的点积
src.y = N*H        // 法线与半向量的点积
src.z = ignored    // 该值将被忽略
src.w = exponent   // 该值必须在 -128.0 和 128.0 之间
以下代码片段显示了执行的作用： 
rn.x = 1;
rn.y = 0;
rn.z = 0;
rn.w = 1;

float power = src.w;
const float MAXPOWER = 127.9961f;
if (power < -MAXPOWER)
    power = -MAXPOWER;         // 符合 8.8 固定点格式
else if (power > MAXPOWER)
    power = MAXPOWER;          // 符合 8.8 固定点格式

if (src.x > 0)
{
    rn.y = src.x;
    if (src.y > 0)
    {
        // 允许的近似值为 EXP(power * LOG(src.y))
        rn.z = (float)(pow(src.y, power));
    }
}
log rn, src
全精度对数 log2(x)。此指令占用 10 个指令槽。

logp rn, src
部分精度对数 log2(x)。

max rn, src1, src2
将 src1 和 src2 每个分量中，较大的输出到 rn 中。

min rn, src1, src2
将 src1 和 src2 每个分量中，较小的输出到 rn 中。

rcp rn, src
计算 src 的倒数。

rsq rn, src
计算 src 的倒数平方根。

sge rn, src1, src2
将 src1 的每个分量与 src2 比较，若在此分量中 src1 >= src2，输出 1，否则输出 0。

slt rn, src1, src2
将 src1 的每个分量与 src2 比较，若在此分量中 src1 < src2，输出 1，否则输出 0。

-rn
