GM Gamepad

作者：Lequ
文档创建时间：2025/8/1

在 GameMaker 8.0 中，对手柄的支持很糟糕：

  • 对手柄的控制非常底层，基本把手柄视作一堆按钮与摇杆的集合。
  • 插入了手柄且未启用时会导致游戏变慢（CPU 资源占用极大）。
  • 如果使用了 gm8x_fix 补丁则会导致 GM8 中自带的手柄支持功能失效。
拥有以上特性，使得 GM8 中自带的手柄支持功能几乎无法使用。此扩展就是为了解决以上痛点，并为了更加方便地使用手柄功能而生。
此扩展的 API 尽量贴合现代 GameMaker API（即前 GameMaker Studio 2 的 API），减少学习成本。

检测游戏手柄

此扩展需要在主控对象中每步调用 gamepad_update() 来更新手柄状态。当游戏手柄插入设备（或将其移除）时，gamepad_update() 会返回 true，从而允许您使用适当的函数来处理这种情况。
当游戏手柄连接时，它会被分配一个插槽索引。在插入的游戏手柄数量发生改变时，其分配的插槽索引可能会改变。如果游戏要使用多个手柄时，推荐使用 gamepad_get_id() 来获取手柄的唯一实例 ID。
不同与 GM8 自带的 joystick API 和现代 GameMaker 的 gamepad API，此扩展理论上能支持无限多个手柄，实际上取决于您运行游戏的平台。

手柄映射

此扩展附带了许多基于 SDL 游戏手柄控制器数据库的不同游戏手柄的映射，您应该能在此扩展的文件夹里面找到 GamepadDatabase.txt 文件。
这些映射用于将内置常量重新映射到给定游戏手柄的直接物理输入。如果您想支持其他游戏手柄，可以通过修改 GamepadDatabase.txt 并使用 gamepad_dll_init() 函数加载此文件来做到这一点。

同样，您也可以使用 gamepad_test_mapping() 设置一个映射，使用 gamepad_remove_mapping() 删除映射，具体请参阅自定义映射函数。
