数据结构：树

作者：Lequ
文档创建时间：2025/5/25

树（tree）是一种用来模拟具有树状结构性质的数据集合。它是由n（n>0）个有限节点组成一个具有层次关系的集合。把它叫做“树”是因为它看起来像一棵倒挂的树，也就是说它是根朝上，而叶朝下的。它具有以下的特点：

  • 每个节点都只有有限个子节点或无子节点；
  • 没有父节点的节点称为根节点；
  • 每一个非根节点有且只有一个父节点；
  • 除了根节点外，每个子节点可以分为多个不相交的子树；
  • 树里面没有环路(cycle)
有以下的函数可以操作“树”这种数据结构：


添加：

real ds_tree_create(dynamic rootVal)
创建一个新的 ds_tree，并在它的根节点中设置值。
返回它的 ID。

real ds_tree_node_create(real id, dynamic value)
在已定义的 ds_tree 中的指定节点设置子节点，并设置它的值。
返回它的 ID。

bool ds_tree_node_add(real id, real root)
添加指定节点的子节点。root 为要添加原节点的根节点 ID。若 root 不是根节点，则会切断 root 与原节点之间的关系。
返回是否添加成功。

void ds_tree_copy(real id, real source)
复制指定的 ds_tree 到 source 上。

void ds_tree_add_dir(real id, string dir)
根据指定的分隔符“/”，往指定的 ds_tree 添加子节点。
例如：a/b/c 会形成如下的树结构：
(id)
 └ a (string)
   └ b (string)
     └ c (string)


删除：

void ds_tree_destroy(real id, bool notme)
删除指定节点及其子节点。若 notme 的值为真，则删除范围不会包括自己。

bool ds_tree_node_remove(real id, real n)
移除指定节点的子节点。只切断它们之间的关系，不对当前节点和子节点的内容做任何处理。
返回是否移除成功。

void ds_tree_node_delete(real id, bool isGain)
删除指定的节点，若 isGain 的值为真，且此节点存在子节点，其子节点会接入此节点的父节点上。
若 isGain 的值为假，其子节点不会接入此节点的父节点上。


改变：

void ds_tree_node_set_value(real id, dynamic value)
改变指定节点的值。

bool ds_tree_node_replace(real id, real n, real root)
覆盖指定节点的子节点。root 为要覆盖原节点的根节点 ID。
若 root 不是根节点，则会切断 root 与原节点之间的关系。
返回是否覆盖成功。

bool ds_tree_node_insert(real id, real pos, real root)
在指定节点中的指定位置 pos 插入一个子节点。 root 为要添加原节点的根节点 ID。
若 root 不是根节点，则会切断 root 与原节点之间的关系。
返回是否插入成功。


获取：

dynamic ds_tree_node_get_value(real id)
返回指定节点的值，未找到则返回值 noone。

real ds_tree_count(real id)
返回指定节点下的节点数量(包括自己)。

real ds_tree_node_get_child(real id, real n)
返回指定节点的子节点，未找到则返回值 noone。
因为一个节点可以有多个子节点，所以要写入顺序n。

dynamic ds_tree_node_get_child_value(real id, real n)
返回指定节点的子节点的值，未找到则返回值 noone。

real ds_tree_node_get_child_count(real id)
返回指定节点的子节点数量。

real ds_tree_node_get_child_number(real id)
返回指定节点在父节点下的顺序位置。

real ds_tree_node_get_parent(real id)
返回指定节点的父节点。

dynamic ds_tree_node_get_parent_value(real id)
返回指定节点的父节点的值。

real ds_tree_node_get_root(real id)
返回指定节点所在 ds_tree 的根节点。

bool ds_tree_node_isleaf(real id)
返回指定节点是否为 ds_tree 的终端节点。

bool ds_tree_node_isroot(real id)
返回指定节点是否为 ds_tree 的根节点。

real ds_tree_find_node(real id, dynamic value)
搜寻指定数据在 ds_tree 中的位置，如果数据不在 ds_tree 中，返回 noone。

bool ds_tree_node_exists(real id, real root)
返回指定节点 id 是否是指定节点 root 的子节点。

real ds_tree_node_get_depth(real id)
返回指定节点在整个 ds_tree 中的层级深度。

real ds_tree_node_get_height(real id)
返回指定节点所在层在整个 ds_tree 中的宽度。

real ds_tree_traversal(real id, real order, bool notme)
遍历指定的 ds_tree，并将其中的节点 ID 按照指定规则进行排序，返回排序后的 ds_list 的 ID。
若 notme 的值为真，则排序后的 ds_list 不会包括自己的ID。
以下为 order 所使用的值：

  • tr_levelorder：按照层序遍历的规则来遍历指定的 ds_tree。
  • tr_preorder：以前序遍历的规则来遍历指定的 ds_tree。
  • tr_postorder：以后序遍历的规则来遍历指定的 ds_tree。
  • tr_inorder：以中序遍历的规则来遍历指定的 ds_tree。


字符串：

void ds_tree_write(real id, string path)
将指定的节点及其子节点写入一个文件里。

real ds_tree_read(string path)
将函数 ds_tree_write() 所创建的文件重新编译为一个 ds_tree，并返回其 id。

void ds_tree_debug_write(string id, string path)
将指定的节点及其子节点写入一个文件里。此文件人类是可读的。
