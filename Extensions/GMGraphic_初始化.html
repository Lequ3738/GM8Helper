初始化与信息查询

bool graphic_dll_init(string dll_path)
在使用本扩展的任何功能之前，需要先调用此函数进行初始化。
参数 dll_path 是图形扩展 DLL（GMGraphic.dll）的文件路径。
此函数会注册扩展的全部外部函数，检测当前游戏的图形后端（D3D8 或 D3D9），并根据设备能力创建扩展内部使用的着色器。
如果 DLL 文件不存在，则返回 false，否则返回 true。

void graphic_dll_free()
游戏结束时，调用此函数释放扩展 DLL。

string d3d_dev_get_name()
返回当前图形设备的名称（GPU 名称），例如显卡的型号字符串。

real d3d_dev_get_ps_version()
返回当前图形设备支持的像素着色器版本，结果为版本号乘以 10 的值。
例如支持 Shader Model 1.1 时返回 11，支持 Shader Model 2.0 时返回 20，支持 Shader Model 3.0 时返回 30。
注意：大多数现代 GPU 实际支持的版本更高，但此函数可能不会如实上报。

real d3d_dev_get_point_max_size()
返回当前图形设备支持的最大点图元尺寸。可用于避免盲目设置过大的点尺寸。

real d3d_dev_get_tex_max_width()
返回当前图形设备支持的最大纹理宽度。适用于所有图形资源。

real d3d_dev_get_tex_max_height()
返回当前图形设备支持的最大纹理高度。

real d3d_dev_get_tex_max_stages()
返回当前图形设备可同时使用的最大纹理阶段（纹理单元）数量。此值限制了你能同时绑定的纹理数量。

real d3d_dev_get_tex_mem()
返回当前可用的纹理内存大小（单位：字节）。此值只是一个近似值，并不是显存的总容量。
