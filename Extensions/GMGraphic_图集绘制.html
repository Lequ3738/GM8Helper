图集绘制

本扩展的图集绘制功能覆盖了 GM8 内置的 draw_sprite* 与 draw_background* 系列函数：调用这些函数时，若传入的是图集内的 Image ID（从 100,000 起），则自动从图集绘制；若传入的是普通 GM 资源 ID，则照常委托给 GM 内置绘制。因此你无需区分资源来源，可以始终使用这套函数。
这些函数会批量提交顶点，同一图集内的多次绘制会自动合并为一次绘制调用（DrawCall），大幅提升性能。
参数 rot 为旋转角度，单位为度。
颜色参数使用 GM 颜色常量，Alpha 参数范围为 0 至 1。

图集 Sprite 绘制

bool draw_sprite(real spr, real subimg, real x, real y)
在坐标（x, y）处绘制精灵的一帧。

bool draw_sprite_stretched(real sprite, real subimg, real x, real y, real width, real height)
将精灵的一帧拉伸到给定的宽度和高度后绘制。

bool draw_sprite_part(real sprite, real subimg, real left, real top, real width, real height, real x, real y)
绘制精灵一帧的某一部分。参数 left、top、width、height 是源区域在原图像中的位置和大小，绘制到坐标（x, y）处。

bool draw_sprite_ext(real spr, real subimg, real x, real y, real xscale, real yscale, real rot, real color, real alpha)
以指定的缩放、旋转和颜色绘制精灵的一帧。
参数 xscale 和 yscale 是水平和垂直缩放比例，rot 是旋转角度（度）。

bool draw_sprite_stretched_ext(real sprite, real subimg, real x, real y, real width, real height, real color, real alpha)
将精灵的一帧拉伸到给定尺寸，并以指定的颜色和透明度绘制。

bool draw_sprite_part_ext(real sprite, real subimg, real left, real top, real width, real height, real x, real y, real xscale, real yscale, real color, real alpha)
绘制精灵一帧的某一部分，并应用缩放和颜色。

bool draw_sprite_general(real sprite, real subimg, real left, real top, real width, real height, real x, real y, real xscale, real yscale, real rot, real c1, real c2, real c3, real c4, real alpha)
最通用的精灵绘制函数。绘制精灵一帧的某一部分，应用缩放、旋转，并为四角分别指定颜色。
参数 c1 至 c4 是左上、右上、右下、左下四个角的颜色，alpha 是整体透明度。

图集 Background 绘制

Background 是单帧图像，因此以下函数没有 subimg 参数，其余与 Sprite 版本一一对应。

bool draw_background(real back, real x, real y)
在坐标（x, y）处绘制指定背景。

bool draw_background_stretched(real back, real x, real y, real width, real height)
将指定背景拉伸到给定的宽度和高度后绘制。

bool draw_background_part(real back, real left, real top, real width, real height, real x, real y)
绘制指定背景的某一部分。参数含义与 draw_sprite_part() 相同。

bool draw_background_ext(real back, real x, real y, real xscale, real yscale, real rot, real color, real alpha)
以指定的缩放、旋转和颜色绘制指定背景。

bool draw_background_stretched_ext(real back, real x, real y, real width, real height, real color, real alpha)
将指定背景拉伸到给定尺寸，并以指定的颜色和透明度绘制。

bool draw_background_part_ext(real back, real left, real top, real width, real height, real x, real y, real xscale, real yscale, real color, real alpha)
绘制指定背景的某一部分，并应用缩放和颜色。

bool draw_background_general(real back, real left, real top, real width, real height, real x, real y, real xscale, real yscale, real rot, real c1, real c2, real c3, real c4, real alpha)
最通用的背景绘制函数。参数含义与 draw_sprite_general() 相同。

bool force_draw_to_screen()
强制刷新当前的图集绘制批次，立即将已累积的绘制提交到屏幕。
通常在切换图集或需要保证绘制顺序时调用。

图集资源查询

以下函数覆盖了 GM8 内置的同名资源查询函数：传入图集内的 Image ID（从 100,000 起）时返回图集资源的信息，传入普通 GM 资源 ID 时返回 GM 内置查询结果。

bool sprite_exists(real id)
检测给定的 ID 是否为有效的图集 Sprite（也接受普通的 GM Sprite ID）。

bool background_exists(real id)
检测给定的 ID 是否为有效的图集 Background（也接受普通的 GM Background ID）。

real sprite_get_number(real id)
返回图集 Sprite 的子图像数量。

string sprite_get_name(real id)
返回图集 Sprite 的名称。

string background_get_name(real id)
返回图集 Background 的名称。

real sprite_get_xoffset(real id)
返回图集 Sprite 的 X 偏移量。

real sprite_get_yoffset(real id)
返回图集 Sprite 的 Y 偏移量。
