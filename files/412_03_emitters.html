发射器

发射器创建粒子。可以使用适当的函数来持续发射或是突然爆发式发射粒子。一个粒子系统可以拥有任意数量的发射器。发射器有以下属性 :
  • xmin, xmax, ymin, ymax 设定粒子产生的区域范围 .
  • shape 设定区域的形状。可以有下列几种 :
    • ps_shape_rectangle 矩形
    • ps_shape_ellipse 椭圆形
    • ps_shape_diamond 菱形
    • ps_shape_line 线形
  • distribution 设定产生粒子的分布状态。可以有以下几种:
    • ps_distr_linear 设定为线性分布，在区域内的任何位置分布几率都相等
    • ps_distr_gaussian 设定为高斯分布，粒子在中心区域生成较多
    • ps_distr_invgaussian 这表明逆高斯分布,其中边缘粒子产生的较多
  • particle type 设定产生粒子的类型
  • number 设定每步产生的粒子数量。如果值比 0 小， 每步都有 -1/ 数量的可能产生粒子。比如说一个值为 -5 的粒子平均每 5 步产生一次 。

下列函数可用于设置发射器，并让他创建粒子。注意，每个发射器的第一个参数都是粒子系统的索引名 。

part_emitter_create(ps) 创建指定粒子系统的发射器。返回值为发射器的索引名。设置发射器的其他属性时需要调用到索引名。
part_emitter_destroy(ps,ind) 销毁粒子系统的发射器 ind 。不再使用时记得调用这个函数来释放空间。
part_emitter_destroy_all(ps) 销毁粒子系统创建的所有发射器。
part_emitter_exists(ps,ind) 返回值为指定粒子系统的发射器是否存在。
part_emitter_clear(ps,ind) 清除发射器 ind 并恢复到默认设置。
part_emitter_region(ps,ind,xmin,xmax,ymin,ymax,shape,distribution) 设置发射器的区域和分布方法。
part_emitter_burst(ps,ind,parttype,number) 突然爆发式发射指定类型的粒子。
part_emitter_stream(ps,ind,parttype,number) 每步都发射指定类型的粒子。 如果值比 0 小， 每步都有 -1/ 数量的可能产生粒子。比如说一个值为 -5 的粒子平均每 5 步产生一次 。
