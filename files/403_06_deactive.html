停用实例

请注意，该功能主要是为了向后兼容。有时停用和激活实例会发生一些意想不到的问题，因此强烈建议不要使用此功能，除非是非常简单的情况，如下所述：

在平台游戏中，你创建了一个大房间，但是视野却是小号的，导致很多实例在视野的外面。这些视野外的实例仍然是激活状态并且会照常执行他们的事件。同样，计算碰撞检测时这些实例也会加入计算，这可能会花费大量的时间在没有必要的事情上。（视野外的实例是否移动通常并不重要）为了解决这个问题， Game Maker 内含了一些函数来停用和激活实例，在使用它们之前，你必须清楚地了解它们是如何工作的。

当您停用实例时，实例在某种意义上被从游戏中移除，他们不再可见也不会执行任何事件。所以对所有的函数和动作来说，它们是不存在的，例如，当销毁特定对象的所有实例时，停用的实例不会被删除（因为它们不存在），这样节省了大量的时间，但使用时要非常小心，因此不要认为玩家拾取的钥匙可以解锁已停用的门。另外，即使实例是持久的，被禁用后在房间切换时也不会移动到下一个房间。请确保在禁用一个实例后，不再对它执行代码，实例在停用自己的时候会执行完后面的代码，一般来说最好不要让一个实例去停用它自己。

最要命的问题是，你不能把负责用来激活其他实例的实例停用了。为了避免这种情况，下面的一些函数允许在停用实例时，不停用调用该函数的实例。

以下是可用的函数： 

instance_deactivate_all(notme) 停用房间内的所有实例。如果参数 notme 为 true （ 1 ）调用该函数的实例不会被停用（一般情况下都填写为1）。
instance_deactivate_object(obj) 停用房间内的所有 obj 的实例。你也可以参数 obj 改为 all 来使所有的实例停用或者指定实例 id 名停用一单个的实例。
instance_deactivate_region(left,top,width,height,inside,notme) 停用指定区域内的所有实例（那些碰撞盒部分在区域内的也算）。如果参数 inside 为 false （ 0 ），则完全露在区域外的实例会被停用。如果参数 notme 为 true （ 1 ），则调用这个函数的实例不会被停用（一般情况下都填写为1）。
instance_activate_all() 激活房间内的所有实例。
instance_activate_object(obj) 激活房间内的所有 obj 的实例。你也可以参数 obj 改为 all 来使所有的实例激活或者指定实例 id 名激活一单个的实例。
instance_activate_region(left,top,width,height,inside)激活指定区域内的所有实例。如果参数 inside 为 false （ 0 ），完全露在区域外的实例会被激活。

举例来说，视野外的实例都停用，视野内的实例全激活，你可以将下面的代码放到移动角色的步事件中: 

{
  instance_activate_all();
  instance_deactivate_region(view_xview[0],view_yview[0],
                        view_wview[0],view_hview[0],false,true);
}

实际上，您可能需要使用比视野稍大的区域。
