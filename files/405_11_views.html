视角

就像你知道的那样在设计房间时你可以最多定义8个不同的视角位置。一个视角由房间的视角区域和屏幕上的视点组成（确切的说是屏幕上的绘图区域内）。使用视角你可以在屏幕的 每一步中显示房间的不同部分。当然，你可以指定一个特定的对象始终可见。

你可以通过一些代码控制视角。你可以让视角可见或隐藏，并在绘图区域中改变视角的位置 或者大小，又或者在房间中改变视角的位置和大小（尤其在你想设定房间里所有对象都不可 见的时候）。你可以从水平和垂直两个方向上对可视对象周围视角的大小进行调整，同时你 可以指定哪些对象在视角中可见。后面这些应用在重要对象在游戏中有所改变时比较重要。 例如，你可能会根据对象所处的状态改变主要角色对象。不幸的是，这个对象需要在视角中 不可见。这可以通过一段简单的代码完成: 

{
  view_object[0] = object_index;
}

以下几个变量决定了视角的各项属性。除了前两个之外其他几个变量都是从0到7的八个不同 数组元素。

view_enabled 返回视角是否启用。
view_current* 返回当前使用的视角（编号0到7）。只在绘图事件中使用。你可以检查这个 变量以确保在某一个视角中进行绘图。变量无法改动。
view_visible[0..7] 返回指定的视角是否在屏幕上可见。

view_xview[0..7] 返回视角在房间的横坐标位置。
view_yview[0..7] 返回视角在房间的纵坐标位置。
view_wview[0..7] 返回视角在房间的宽度。
view_hview[0..7] 返回视角在房间的高度。
view_xport[0..7] 返回绘图区域内视点的横坐标。
view_yport[0..7] 返回绘图区域内视点的纵坐标。
view_wport[0..7] 返回绘图区域内视点的宽度。
view_hport[0..7] 返回绘图区域内视点的高度。
view_angle[0..7] 房间内视角的旋转角度。（逆时针，单位角度）
view_hborder[0..7] 可见对象周围边框的水平尺寸（单位像素）。
view_vborder[0..7] 可见对象周围边框的垂直尺寸（单位像素）。
view_hspeed[0..7] 视角的最大水平速度。
view_vspeed[0..7] 视角的最大垂直速度。
view_object[0..7] 视角中必须保持可见的对象实例。如果有多个实例则只有第一个算数。 你可以分配一个实例 id 到这个变量上。这样特定的实例就被指定。

注意屏幕上图像的尺寸由房间开始时指定的可见视角决定。如果你在游戏中改变了视角，他 们可能无法符合屏幕尺寸。屏幕尺寸并不会自动适应。所以你需要自己去操作，使用如下几 个函数 :

window_set_region_size(w,h,adaptwindow) 设置窗口中的绘图区域宽度和高度。 adaptwindow 参数指定窗口尺寸是否一定要适应绘图区域大小。窗口尺寸在你使用固定缩放 比例时将总是适应。（请看函数 window_set_region_scale() 相关内容。）
window_get_region_width() 返回当前绘图区域的宽度。
window_get_region_height() 返回当前绘图区域的高度。

在游戏中你经常需要知道鼠标的位置。通常你会使用变量 mouse_x 和 mouse_y 来获取坐标 。当使用多个视角时，这些变量给出的是鼠标在当前视角内的坐标。有时候，你可能需要知 道鼠标在特定视角内的坐标，或者当鼠标离开当前视角后的坐标。以下函数就是为这样的情 况准备的。

window_view_mouse_get_x(id) 返回鼠标在编号为 id 的视角内的横坐标。
window_view_mouse_get_y(id) 返回鼠标在编号为 id 的视角内的纵坐标。
window_view_mouse_set(id,x,y) 在编号为 id 的视角内设置鼠标坐标为(x,y)。
window_views_mouse_get_x() 功用同 mouse_x 。
window_views_mouse_get_y() 功用同 mouse_y 。
window_views_mouse_set(x,y) 设置当前可见的第一个视角内的鼠标坐标为(x,y)。
