绘制3D多边形

问题是在旧的方式中绘制精灵或多边形的总是在xy坐标上,他们全部角都有相同深度.在真3D你想能在够在垂直方向上有不同深度.从这一刻起我们将谈论关于Z坐标取代深度.因此我们想明确坐标如(x,y,z)组合.为这个特殊版本有高级绘制函数:

d3d_primitive_begin(kind) 设置3D多边形样式,pr_pointlist(点组), pr_linelist(线组), pr_linestrip(线片), pr_trianglelist(三角组), pr_trianglestrip(三角片) 或 pr_trianglefan.(三角扇)
d3d_vertex(x,y,z) 增加顶点(x,y,z)到多边形,在设定之前定义颜色和透明.
d3d_vertex_color(x,y,z,col,alpha) 增加顶点(x,y,z)到多边形,并且设定它的颜色和透明值,这函数允许你创造平滑改变颜色和透明的多边形.
d3d_primitive_end() 结束描述多边形,这个函数实际上在绘制它.

例如绘制一个四面体(金字塔3面)站立在z=0平面到顶点z=200,你能使用下面代码: 

{
  d3d_primitive_begin(pr_trianglelist);
    d3d_vertex(100,100,0);
    d3d_vertex(100,200,0);    
    d3d_vertex(150,150,200);
    d3d_vertex(100,200,0);
    d3d_vertex(200,200,0);    
    d3d_vertex(150,150,200);
    d3d_vertex(200,200,0);
    d3d_vertex(100,100,0);    
    d3d_vertex(150,150,200);
    d3d_vertex(100,100,0);
    d3d_vertex(100,200,0);    
    d3d_vertex(200,200,0);
  d3d_primitive_end();
}

现在你如果想使用它,很可能你将只看到一个三角形在屏幕上,因为在四面体顶部你的视点,同时使用一种颜色很难看出不同面貌.下面我们将看到如何改变视点,配置使用颜色draw_set_color(col)函数在增加顶点之前.

你也能使用贴图在3D多边形中.它要求与文档描述中的高级功能完全相同.但是这时你需要基本函数的3D形式.你必须认识到一件事.在一个贴图位置(0,0)是左上角,但是通常使用投影(如下所示),左下脚是(0,0)点.如此你可能需要垂直翻转贴图(纹理).

d3d_primitive_begin_texture(kind,texid) 设置3D开始颜色和贴图
d3d_vertex_texture(x,y,z,xtex,ytex) 增加顶点(x,y,z)和贴图(xtex,ytex),在之前设定颜色和透明度为混合.
d3d_vertex_texture_color(x,y,z,xtex,ytex,col,alpha) 增加顶点(x,y,z)和贴图(xtex,ytex),并为混合设定颜色和透明度
d3d_primitive_end() 结束描述多边形,这个函数实际上在绘制它.

因此,例如你能使用下列代码绘制一个背景图片在隐藏距离中 

{
  var ttt;
  ttt = background_get_texture(back);
  d3d_primitive_begin_texture(pr_trianglefan,ttt);
    d3d_vertex_texture(0,480,0,0,0);
    d3d_vertex_texture(640,480,0,1,0);    
    d3d_vertex_texture(640,480,1000,1,1);
    d3d_vertex_texture(0,480,1000,0,1);
  d3d_primitive_end();
}

一个三角形有前边和后边,在前边定义在逆时针方向上定义的顶点位置的边.通常两边都要取用,但是如果你制作一个封闭的形状这一种浪费因为后面的三角 不能被看到.在这种情况下你可以选择后面剔除.这样节约一半的绘制时间,但是它偏离了你绘制多边形定义的正确方法,存在下面函数.:

d3d_set_culling(cull)设置开始背面剔除 (true) 或者关闭背面剔除 (false).
