If 语句

if语句的形式 

if (<表达式>) <语句>

或 

if (<表达式>) <语句> else <语句>

<语句>也可以是一段语句体。表达式会进行运算求值。如果括号内的（四舍五入后的）结果 <=0 （或者是false） ，else 后面的语句就会执行。否则（表达式为true的时候），另一个语句就会执行。 在语句前后加上花括号是个很好的习惯。最好使用下面的书写格式 

if (<expression>)
{
  <statement>
}
else
{
  <statement>
}

例子
一下一段程序可以让对象向屏幕中心移动. 

{
  if (x<200) {x += 4} else {x -= 4};
}
