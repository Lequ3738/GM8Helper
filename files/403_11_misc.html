杂项函数和变量

这里有一些处理出错的变量和函数。
error_occurred 表示是否有错误发生。
error_last 用字符串显示最后出错的信息
show_debug_message(str) 在Debug模式中显示一条字符串
debug_mode 这个只读变量表示游戏是否处于debug模式
下面的变量可以确保你的游戏运行在适当的版本上
gamemaker_pro 游戏是否是用专业版创建的。
gamemaker_registered 同gamemaker_pro
gamemaker_version GameMaker的版本号，是一个整数。如果是8.0的版本，则可能是800到809中的数字，如果是8.1将会是810到819，等等. 所以它是用来检查一个范围而不是一个特定的版本. 这个变量在8.0版本以前不可用

下面的函数用来监测是否确定变量的存在以及怎样设置变量及获取他们的值。所有这些函数的变量名都是用字符串传递。

variable_global_exists(name) 返回全局变量name是否存在（参数name为字符串）
variable_local_exists(name)返回局部变量name是否存在（参数name为字符串）
variable_global_get(name)返回全局变量name的值（参数name为字符串）
variable_global_array_get(name,ind) 返回全局一维数组name[ind]的值（参数name为字符串）
variable_global_array2_get(name,ind1,ind2) 返回全局数组name[ind1,ind2]的值（参数name为字符串）
variable_local_get(name) 返回局部变量name的值（参数name为字符串）
variable_local_array_get(name,ind) 返回局部一维数组name[ind]的值（参数name为字符串）
variable_local_array2_get(name,ind1,ind2) 返回局部二维数组name[ind1,ind2]的值（参数name为字符串）
variable_global_set(name,value) 设置全局变量name的值为value（参数name为字符串）
variable_global_array_set(name,ind,value) 设置全局一维数组name[ind]的值为value（参数name为字符串）
variable_global_array2_set(name,ind1,ind2,value) 设置全局二维数组name[ind1,ind2]的值为value（参数name为字符串）
variable_local_set(name,value) 设置局部变量name的值为value（参数name为字符串）
variable_local_array_set(name,ind,value) 设置局部一维数组name[ind]的值为value（参数name为字符串）
variable_local_array2_set(name,ind1,ind2,value) 设置局部二维数组name[ind1,ind2]的值为value（参数name为字符串）

举个例子，你可以这样写： 

{
  if variable_global_exists('ammunition')
    global.ammunition += 1
  else
    global.ammunition = 0
}

你可以使用这些函数通过一种参数传递的方法给脚本传递变量，通过传递它们的字符名以使用函数来改变它们

你可以使用下面的函数改变程序的优先级 :

set_program_priority(priority)设置程序的优先级。可以指定 -3 到 +3 之间的值。值为 -3 时意味着程序只会在如下情况运行，电脑没有其他程序要处理时，或是所有其他的程序都空闲时。值为 -2 或 -1 时在正常线下，其他程序会有优先权。值为 0 时是正常的值。值为 +1 或 +2 为较高的优先级，可能会导致较高的速度和较平滑的游戏流程。但其他程序会得到很少的处理时间。值为 +3 时为实时模式。在实时模式中基本上所有的时间都分配到游戏当中去了。这样会导致电脑正在运行的其他应用程序发生严重的问题。当然键盘事件不再被电脑记录下来。所以只有当你想要所有的处理时间时才使用这个函数。同样要注意最好使用前仔细的检查一下并且运行前保存游戏。
