路径

可以创建路径并添加路径节点。无论如何，决不改变实例正在使用的路径。会导致不可预期的结果。有以下函数 :

path_set_kind(ind,val) 设置指定所有的路径的连接类型（ 0= 直的， 1= 平滑的）。
path_set_closed(ind,closed) 设置路径是否闭合。（ true 或 false ）
path_set_precision(ind,prec) 设置平滑路径计算的精密度（ 1 到 8 ）。
path_add() 添加一个新的空白路径。返回路径索引。
path_delete(ind) 删除指定索引的路径。
path_duplicate(ind) 创建指定索引路径的复制品。返回拷贝的索引。
path_assign(ind,path) 分配指定路径为路径 ind 。这制作了一个路径的拷贝。用这个方法可以很容易的将一条现有的路径设置为一条不同的路径，例如新的路径。
path_append(ind,path)附加指定路径为路径 ind 。
path_add_point(ind,x,y,speed) 附加指定路径为路径 ind 。
path_insert_point(ind,n,x,y,speed) 在（ x ， y ）位置使用给定 speed 速度，在指定索引路径的 n 节点前插入路径节点。
path_change_point(ind,n,x,y,speed) 在（ x ， y ）位置使用给定 speed 速度，改变指定索引路径的 n 节点。
path_delete_point(ind,n) 删除指定索引路径的 n 节点。
path_clear_points(ind) 清除路径所有的节点，使它变成空白路径。
path_reverse(ind) 反转路径。
path_mirror(ind) 水平镜像翻转路径（根据中心点）。
path_flip(ind) 垂直翻转路径（根据中心点）。
path_rotate(ind,angle) 顺时针旋转路径 angle 角度（绕中心点）。
path_scale(ind,xscale,yscale) 使用指定参数缩放路径（从中心点）。
path_shift(ind,xshift,yshift)根据指定量平移路径。
