弹出信息和询问框

有大量的函数关于弹出信息，询问，选择菜单，或是一段对话，玩家可以输入数字，字符串或是设定颜色或文件名 :

show_message(str) 显示一个对话框，里面的信息为字符串。
show_message_ext(str,but1,but2,but3) 显示一个对话框，里面的信息为字符串，上面还有三个按钮。参数 but1, but2 以及 but3 包含了按钮的文本。空的字符串表示按钮不显示。文本中你可以使用 & 符号来设定下一个用作快捷键的按钮。函数返回值为按下按钮的编号（ 0 为 Esc 键）。
show_question(str) 显示一个询问框，玩家选 yes 时返回 true ， no 时返回 false 。
get_integer(str,def) 显示一个数字输入框。参数 str 是信息。参数 def 是默认显示的数字。
get_string(str,def) 显示一个文字输入框。参数 str 是信息。参数 def 是默认显示的值。
message_background(back) 设置上列所有函数的弹出框的背景图。参数 back 必须是某游戏中定义的背景。如果 back 有透明度，信息图像同样也有透明度（ windows2000 或随后的版本才可以）。
message_alpha(alpha) 设置上列所有函数的弹出框为 alpha 半透明。参数 alpha 必须在 0 （完全透明）到 1 （不透明）之间（ windows2000 或随后的版本才可以）。
message_button(spr) 设置用于弹出框按钮的精灵。参数 spr 必须是一个包含三个图像的精灵，第一个设定未按下及鼠标离开时的按钮，第二个为鼠标进入但没有按下，第三个为按下按钮的图像。
message_text_font(name,size,color,style) 设置弹出框里文字的字体。（这个是一般的 windows 字体，不是你游戏中可以显示的字体资源）参数 style 设定字体风格（ 0 为正常， 1 为粗体， 2 为斜体， 3 为粗斜体）。
message_button_font(name,size,color,style) 设置弹出框里按钮的字体。参数 style 设定字体风格（ 0 为正常， 1 为粗体， 2 为斜体， 3 为粗斜体）。
message_input_font(name,size,color,style) 设置弹出框里输入框的字体。参数 style 设定字体风格（ 0 为正常， 1 为粗体， 2 为斜体， 3 为粗斜体）。
message_mouse_color(col) 设置弹出框里鼠标进入按钮时按钮字体的颜色。
message_input_color(col) 设置弹出框里输入框的背景色。
message_caption(show,str) 设置弹出框的标题。参数 show 为是否显示边框，边框显示时用参数 str 设定标题。
message_position(x,y) 设置弹出框在屏幕上的位置。 使用-1为到中心位置.
message_size(w,h) 固定弹出框在屏幕上的尺寸。如果宽选-1宽为图片宽。如果高选-1高为图片高是计算线路数量的消息框.
 show_menu(str,def) 显示一个弹出菜单。参数 str 设定菜单文字。菜单由不同的菜单项目（带有垂直条）组成。例如， str = 'menu0|menu1|menu2' 。第一个项目选定时，返回 0 ，以此类推。玩家没有选择项目时，返回默认值 def 。
show_menu_pos(x,y,str,def) 同上个函数一样显示弹出菜单，不过这个函数还指定菜单在屏幕上的位置。
get_color(defcol) 获取玩家选哪个颜色。参数 defcol 为默认颜色。如果玩家按下 Cancel 键，返回值为 -1 。
get_open_filename(filter,fname) 获取玩家打开指定的文件夹的文件名。文件夹形式为 'name1|mask1|name2|mask2|...' 。不同的选项之间隐藏了一个分号。 * 意为任何字符串。例如： 'bitmaps|*.bmp;*.wmf' 。如果玩家按下 Cancel 键，返回值为空字符串。
get_save_filename(filter,fname) 获取储存文件的文件名。如果玩家按下 Cancel 键，返回值为空字符串。
get_directory(dname) 获取目录。参数 dname 为默认名。如果玩家按下 Cancel 键，返回值为空字符串。
get_directory_alt(capt,root) 可选择的方法获得目录。参数 capt 为显示的标题。参数 root 为显示根目录。使用空字符串来显示整个目录。如果玩家按下 Cancel 键，返回值为空字符串。
show_error(str,abort) 显示标准出错信息（和 / 活写入日志）。参数 abort 设定是否中断游戏 。
