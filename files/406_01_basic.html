基本声音函数

这里有五个基本声音函数，两个关于播放，一个关于检测声音是否正在播放，还有两个是关于停止声音的。大部分函数将声音的索引名作为参数。声音的名字就是它的索引名。你也可以将索引名存入一个变量，然后再使用它 。

sound_play(index) 指定的声音播放一次。如果声音是背景音乐，当前背景音乐停止播放。
sound_loop(index) 播放指定的声音，不断循环。如果声音是背景音乐，当前背景音乐停止播放。
sound_stop(index) 停止播放指定的声音。如果同时播放多个 index 声音，所有的声音全部停止播放。
sound_stop_all() 停止播放所有的声音。
sound_isplaying(index) 返回值为指定的声音是否正在播放。注意，函数的返回值在声音确实通过扬声器播放时才为 true 真。调用函数播放一个声音时，并不会立即传达到扬声器那里，所以那时函数可能返回值 false 。同样，尽管声音停止了你还能听到一会儿（比如因为回声），函数仍然会返回 true 值。

可以进一步使用音效。你可以改变音量和声道，左声道或是右声道。音量只能减少。这些函数对通过媒体播放器播放的格式无效（类似 mp3 格式） 。

sound_volume(index,value) 改变指定声音的音量（ 0 为最低， 1 为最高）。
sound_global_volume(value) 改变所有声音的全局音量。（ 0 为最低， 1 为最高）。
sound_fade(index,value,time) 在指定时间 time 内（单位毫秒）改变指定声音的音量为新的值（ 0 为最低， 1 为最高）。用于音乐的淡入淡出。
sound_pan(index,value) 改变指定声音的声道（ -1 为左， 0 为中间， 1 为右）。
sound_background_tempo(factor) 改变背景音乐的速度（midi格式）。参数factor为速度的倍数。所以值为1时对应的是正常速度。大的值对应快速，小的值对应慢速。值必须在0.01到100之间。

除了 midi 和 wave （和 mp3 格式）实际上还可以播放第四种类型： direct 音乐格式。扩展名为 .sgt 。这样的文件格式经常有其他文件的描述，比如乐队或风格的介绍。为了找出这些格式，声音系统必须知道它们的位置。你可以使用下列函数设置文件的搜索路径目录。注意，必须自己添加文件。 Game Maker 不会自动包含这样的附加文件。

sound_set_search_directory(dir) 设置 direct 音乐格式的路径目录。参数 dir 应该不包含最后的反斜线符号 。
