CD 音乐

这些函数只有 Game Maker 注册版本才能使用 。

这里有大量的函数出理用 CD 播放音乐 。

cd_init() 使用其它函数前必须调用这个函数。 CD 更换时也要调用（有时候）。
cd_present() 返回值为 CD 当前是否在默认光驱内。
cd_number() 返回值为 CD 的音轨数。
cd_playing() 返回值为 CD 是否正在播放。
cd_paused() 返回值为 CD 是否暂停或者停止播放。
cd_track() 返回值为当前音轨的编号（ 1 为第一个）。
cd_length() 返回值为 CD 的总长度，单位为毫秒。
cd_track_length(n) 返回值为 CD 音轨 n 的长度，单位为毫秒。
cd_position() 返回值为在 CD 上的当前位置，单位为毫秒。
cd_track_position() 返回值为当前播放音轨的位置，单位为毫秒。
cd_play(first,last) 设定 CD 从 first 开始播放到 last 。如果要播放整张 CD ，使用参数 1 和 1000 。
cd_stop() 停止播放。
cd_pause() 暂停播放。
cd_resume() 继续播放。
cd_set_position(pos) 设置在 CD 上的位置，单位为毫秒。
cd_set_track_position(pos) 设置当前音轨的位置，单位为毫秒。
cd_open_door() 弹出光驱。
cd_close_door() 关闭光驱。

这个是 windows 多媒体功能的常用函数。

MCI_command(str) 这个函数通过多媒体控制接口（MCI）发送字符串命令到windows多媒体系统。返回值为字符串。你可以使用这个函数控制所有类型的多媒体设备。查看windows帮助看看如何使用这个命令。例如MCI_command('play cdaudio from 1')播放cd（在你使用其它命令正确的初始化后）。这个函数只提供给高级用户使用。
