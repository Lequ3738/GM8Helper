路径

下列函数介绍路径 :

path_exists(ind) 返回值为指定索引号的路径是否存在。
path_get_name(ind) 返回值为指定索引号的路径名字。
path_get_length(ind) 返回值为指定索引号的路径长度。
path_get_kind(ind) 返回值为指定索引号的路径的连接类型（ 0= 直的， 1= 平滑的） 。
path_get_closed(ind) 返回值为指定索引号的路径是否闭合。
path_get_precision(ind) 返回值为指定索引号的路径创建平滑路径使用的精度。
path_get_number(ind) 返回值为指定索引号的路径的定义点的数量。
path_get_point_x(ind,n) 返回值为指定索引号的路径的第 n 个定义点的 x 坐标。 0 为第一个点。
path_get_point_y(ind,n) 返回值为指定索引号的路径的第 n 个定义点的 y 坐标。 0 为第一个点。
path_get_point_speed(ind,n) 返回值为指定索引号的路径的第 n 个定义点的速率。 0 为第一个点。
path_get_x(ind,pos) 返回值为指定索引号的路径的 pos 位置的 x 坐标。参数 pos 必须在 0 到 1 之间。
path_get_y(ind,pos) 返回值为指定索引号的路径的 pos 位置的 y 坐标。参数 pos 必须在 0 到 1 之间。
path_get_speed(ind,pos) 返回值为指定索引号的路径的pos位置的速率。参数pos必须在0到1之间。
