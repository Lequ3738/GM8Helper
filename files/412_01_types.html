粒子类型

一个粒子类型可描述为某特殊类粒子的形状，颜色，运动，及其它属性。你只需要在游戏开始时定义一个粒子类型一 次。随后可以在游戏中随意使用任何粒子系统。粒子类型拥有大量的参数可以供你使用和发挥。设置正确的话，你就能创建大部分你所喜欢的任何效果。下面我们来 讨论如何设置 。

某些程序在创造了新的粒子类型后，会破坏他们以前的类型 :

part_type_create() 创建一个新的粒子类型。返回值为类型的索引名。索引可能用于下面的函数调用来设置粒子类型的属性。所以尽量保存在全局变量中，因为你可能会在任何一个物体使用他。
part_type_destroy(ind) 销毁 ind 的粒子类型。如果不再需要时调用这个函数释放空间。
part_type_exists(ind) 返回值为指定的粒子类型是否存在。
part_type_clear(ind) 清除 ind 的粒子类型，并恢复到默认设置。

粒子的形状

每个粒子都有一个形状。形状由一个精灵描绘。你可以使用任何你喜欢的精灵，还可以使用内建的 15 种精灵。它们的大小全部为 64x64 ，并且可以设置透明值使它们能精细的融入背景。形状由以下常量指定 :
  • pt_shape_pixel 像素点
  • pt_shape_disk 圆盘
  • pt_shape_square 正方形
  • pt_shape_line 线形
  • pt_shape_star 星星
  • pt_shape_circle 圆形
  • pt_shape_ring 环形
  • pt_shape_sphere 球形
  • pt_shape_flare 闪光
  • pt_shape_spark 火星
  • pt_shape_explosion 爆炸
  • pt_shape_cloud 烟云
  • pt_shape_smoke 烟雾
  • pt_shape_snow 雪花

使用以下函数设置形状 :

part_type_shape(ind,shape) 使用上面的任一常量设置粒子类型的形状（默认为 pt_shape_pixel ）。

你也可以使用自己的精灵作为粒子。如果精灵有多层图，你可以从中指定一个。你可以选择一个随机的精灵，使它动起来，动画开始时开始或给一个随机位置。你可以使用以下函数。

part_type_sprite(ind,sprite,animat,stretch,random) 为粒子类型设置自己的精灵。参数 animat （ 1 或 0 ）为指定精灵是否为动画。参数 stretch （ 1 或 0 ）为在粒子存活期内动画是否被拉伸。参数 random （ 1 或 0 ）为开始图是否为随机图 。

一旦为粒子类型选定精灵（不管是默认的形状或是你自己的），就可以指定它们的大小。可以定义某一粒子类型为所有的粒子统一大小或者大小不一。你可以指定大小的范围。当然，也可以指定大小是否在粒子存活期内改变，是否大小有些浮动，造成一种闪光的效果 。

part_type_size(ind,size_min,size_max,size_incr,size_wiggle) 为粒子类型设置大小参数。你要指定开始时的最小尺寸 size_min ，开始时的最大尺寸 size_max ，每步增大的尺寸 size_incr （使用负值减小尺寸），以及偏移量 size_wiggle 。（默认大小为 1 ，默认大小为原始尺寸） 。
part_type_scale(ind,xscale,yscale) 设置水平和垂直的缩放。这个函数用于增加大小。当你想要缩放不同比例时这个函数十分有用 。

粒子有方向的属性。对所有的粒子来说，方向可以一致，也可以不同，并且可以在粒子存活期内改变。角度指定为逆时针旋转，单位为度 。

part_type_orientation(ind,ang_min,ang_max,ang_incr,ang_wiggle,ang_relative) 为粒子类型设置定位角属性。你可以指定最小角度 ang_min ，最大角度 ang_max ，每步增加 ang_incr 的角度偏移量 ang_wiggle 。（默认值全部为 0 ）你可以指定给定角度是否与当前运动方向相关（相关 1 ，相对 0 ）。举例来说，将所有的值除了 ang_relative 都设为 0 ，粒子的方向就会精确的跟随粒子运动的路径 。

颜色与混合

粒子拥有颜色属性。有不同的方式可以为粒子指定颜色。最简单的办法就是指定单色。在粒子存活期间，你也可以为 以内插值替换的粒子颜色指定两个或三个颜色。例如，粒子开始时为白色，然后颜色越来越黑直到存活期结束。另外，你可以在颜色域内指定每个粒子为不同的颜 色。你可以使用 RGB ，或是 HSV 颜色域 。

默认颜色为白色。你要使用自己的精灵，自带颜色时，一般就不用自己设定颜色了 。

part_type_color1(ind,color1) 为粒子指定一个单色。
part_type_color2(ind,color1,color2) 指定两个颜色，会以内插值替换，从颜色 1 变化到颜色 2 。
part_type_color3(ind,color1,color2,color3) 三个颜色中转换，开始时颜色 1 ，粒子存活中期为颜色 2 ，最后为颜色 3 。
part_type_color_mix(ind,color1,color2) 这个函数为指定粒子取得的颜色为两个指定颜色的混合色。颜色在粒子存活期后内保持固定。
part_type_color_rgb(ind,rmin,rmax,gmin,gmax,bmin,bmax) 每个粒子都可以使用一个范围内的固定颜色。使用 RGB 颜色域中的颜色（ 0 到 255 ） 。
part_type_color_hsv(ind,hmin,hmax,smin,smax,vmin,vmax)每个粒子都可以使用一个范围内的固定颜色。使用 HSV 颜色域中的颜色（ 0 到 255 ）

除了颜色，还可以设置 alpha 透明值。 内建的粒子形状的 alpha 透明度都设置好了，你可以使用这些函数制作出粒子消失的效果 。

part_type_alpha1(ind,alpha1) 为粒子类型设置一个 alpha 透明值（ 0 到 1 ）。
part_type_alpha2(ind,alpha1,alpha2) 指定两个透明度，会以内插值替换，从透明度 1 变化到透明度 2 。
part_type_alpha3(ind,alpha1,alpha2,alpha3) 这次是三个透明度之间的转换

一般来说粒子和背景的合成方法和精灵一样。不同处为粒子还可以使用附加合成的方法。这样可以做出一个爆炸的华丽效果 。

part_type_blend(ind,additive) 设置是否使用附加合成（ 1 或 0 ）

存活与消亡

粒子存活有时间限制，称为存活期。过了存活期就粒子消失了。存活期通过步来测定。你可以为每个粒子类型指定存活期（或是存活期的范围）。粒子自己可以创建不同类型的新粒子。有两种方法可以办到。每一步都创建新粒子，或者消亡时创建粒子。注意，粒子的总量不要设得太高 。

part_type_life(ind,life_min,life_max) 为粒子类型设置存活期范围。（默认值为 100 ）
part_type_step(ind,step_number,step_type) 为指定的粒子类型设置每步都产生的粒子数量和类型。如果使用负值，每步都有 -1/ 数量的可能产生粒子。比如说一个值为 -5 的粒子平均每 5 步产生一次。
part_type_death(ind,death_number,death_type) 设置当指定粒子消亡时产生的粒子数量和类型。同样可以使用负数来 -1/ 数量的可能产生粒子。注意，这些粒子只会在粒子消亡的最后一刻才产生，而不是被破坏器破坏的时候。（参考下面章节） 。

粒子运动

粒子可以在它们的存活期内移动。可以获得一个初速（或是速度范围）和方向，也可以通过时间改变速度和方向。还可以定义重力朝特定方向拉扯粒子。有以下函数可用 :

part_type_speed(ind,speed_min,speed_max,speed_incr,speed_wiggle) 为粒子类型设置速度属性。（默认值全为 0 ）可指定一个最小速和一个最大速。粒子创建时可以在给定范围内选择一个随机值。可以指定速度每步都增加 . 使用负数减慢粒子的速度（速度永远都不会比 0 小）。最后可以指定速度一定的偏移值。
part_type_direction(ind,dir_min,dir_max,dir_incr,dir_wiggle) 为粒子类型设置方向属性。（默认值全为 0 ）你可以指定方向的范围（逆时针， 0 为朝右的方向）。例如，让粒子 0 到 360 度范围内随机移动。你可以每步都指定方向的增量，以及偏移值。
part_type_gravity(ind,grav_amount,grav_dir) 为粒子类型设置重力属性（默认为无重力）。可以指定每步增加重力及方向。例如，使用 270 为朝下的方向。
