3D 音效

这些函数只有 Game Maker 注册版本才能使用 。

3D 声效是关于声音到听众的位置（和速率）。尽管 3D 音效大量用于 3D 游戏，你也可以有效地用于 2D 游戏。主要思想就是声音在空间中的位置。在所有的函数中听众的位置都假设为（ 0 ， 0 ， 0 ）。系统根据听众会听到怎样的声音相应调整计算。当你拥有一个好的扬声系统时，效果会非常好，不过只有少部分扬声器支持 。

除了位置，声音还有速率属性。这就是著名的多普勒效应。最后，声音还有一个方向 。

Game Maker 支持 3D 声音选项，通过下列函数操作。他们可以使声音资源指定为 3D 。（缺点是 3D 声是单声道的，不是立体声。）

sound_3d_set_sound_position(snd,x,y,z) 设置声音的位置，空间中关系到听众的指定位置。在 x 轴上的音量从左至右增加，在 y 轴上的音量从下往上增加，在 z 轴上的音量从近到远增加。值用米为单位测量。声音可以听到的音量依赖于这个测量值，和真实世界里的一样。
sound_3d_set_sound_velocity(snd,x,y,z) 设置声音的速率，空间中指定声音速率的向量值。请注意，设置速率并不意味着位置的改变。速率仅仅是用来计算多普勒效应的。所以，如果你想移动速度，你必须自己改变声音的位置。
sound_3d_set_sound_distance(snd,mindist,maxdist) 设置声音不再增加响度的最小距离，还有声音不再能听到的最大距离。所以，当距离在 0 和最小距离之间时，为最大振幅。振幅在最小距离和最大距离之间时缓慢增长直到抵达最大距离，或者直到声音无论如何都听不见时停止增长。默认最小距离为 1 米 ，最大距离为 10 亿米。
sound_3d_set_sound_cone(snd,x,y,z,anglein,angleout,voloutside) 正常的声音在指定距离的所有的方向上有相同的振幅。你可以设置声音为锥形传播并且改变声音的方向。参数x，y，z设定锥形声音的方向。参数anglein 设定内角。如果听众在这个角度内，它听到的声音就是正常的。参数angleout设定外角。听众在外角外时，音量由参数voloutside设定。更精确 的设置，参数voloutside是负数时，从内部音量中减去数百分贝。内角和外角之间的音量逐渐减少。
