Switch 语句

有些时候你希望让你的行动由某些特定的值决定。你可以使用一串 if 语句来实现。但这里 有一种更加简单的方式， switch 语句。switch 语句有如下格式： 

switch (<表达式>)
{
  case <表达式1>: <语句1>; ... ; break;
  case <表达式2>: <语句1>; ... ; break;
  ...
  default: <语句>; ...
}

这段语句的效果如下：首先表达式进行运算。然后结果会同 case 后面的表达式的结果进行 比较。相同的结果就会执行后面相应的语句。如果没有一个相同，则执行 default 后的语 句。当然， break 不是必须的。如果里面没有 break 语句，程序会简单的进入下一个 case 语句。

示例
如下一段程序的效果是在不同的按键被按下后执行相应的动作. 

switch (keyboard_key)
{
  case vk_left:
  case vk_numpad4:
    x -= 4; break;
  case vk_right:
  case vk_numpad6:
    x += 4; break;
}
