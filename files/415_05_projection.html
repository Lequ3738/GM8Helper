世界视角

默认是你看到沿着Z轴看着向房间中间移动,通常3D游戏你想改变你看到的世界.举例如,在第一人称射击你可能想有镜头从原离xy平面的坐标查看.在绘制队伍时你设定正确的投影,改变你看的方式有以下两个函数.

d3d_set_projection(xfrom,yfrom,zfrom,xto,yto,zto,xup,yup,zup) 定义怎么看世界.你必须是从一点看向另外一点.

这个函数需要解释.首先需要你从什么位置看的坐标这个设定为(xfrom,yfrom,zfrom),其次你需要向什么方向看,这时需要设定第二个 坐标点(xto,yto,zto),最后你能旋转镜头围绕这个视点的方向.我们就必须获得一个载体,那就是指向方向的摄像机.这时由3个参数组成 (xup,yup,zup).让我们举个例子.如你能在延着xy平面的第一人称射击使用. 

{
  d3d_set_projection(100,100,10,200,100,10,0,0,1);
}
因此你看到的从点(100,100)高度为10的平面上指向(200,100). 位于(x,y)载体是Z向规定. 使这个稍为复杂, 假设你有一个房间,如您定位的摄像机. 它将改正(x,y)的位置和方向(也可能是速度). 这说明,现在你可以用你的摄像机以下代码: 

{
  with (obj_camera)
    d3d_set_projection(x,y,10,
               x+cos(direction*pi/180),y-sin(direction*pi/180),10,
               0,0,1);
}

这点可能有点复杂.我们从摄像机点(x,y)离地面10得位置.确定点得正确方向我们需要做点算术运算.这个点是3维坐标起点方向.最后我们所用向量在上面.

重要的说明!当GameMaker开始绘制在房间中它将设定视角点返回默认位置,因此首先我们必须在绘制界面时设置你想要的视角.这必须在绘制事件中执行!

还有一个函数扩展版本。:

d3d_set_projection_ext(xfrom,yfrom,zfrom,xto,yto,zto,xup,yup,zup,angle,aspect,znear,zfar) 这个扩展版本的函数你能确定视角角度,aspect是横向和纵向视角尺寸,远近裁减.

增加的工作参数如下,你制定摄像机视角方向并标出向量,你可能仍然改变摄像机的横向水平.这就叫真实视角.一个真实是45度并默认产生.但是你如果 想改变还是可以改变的.第二你能设定旋转角度在水平和垂直视角上.通常你想使用和房间一样的角度.例如640/480.最后你能切割方向上的图像,通常物 体距离超过zfar是可能被重要设定的原因,因为他们能可能在z轴上被忽略.如果你使用一个太大的精确就可能会错误.默认定义是1到 32000.znear必须大于0! 

有时你需要一个通常的投影当不在3D时或者你想返回默认视角.你能使用下面函数:

d3d_set_projection_ortho(x,y,w,h,angle) 设置正常正投投影在房间上旋转某个角度.
d3d_set_projection_perspective(x,y,w,h,angle) 设置一个正常透视投影在房间的区域.旋转某个角度。

通常投影绘制在表层.例如显示分数或其他表面.因此我们设定一个正投投影绘制视角.我们也必须选择隐藏表面因为我们想绘制信息在正确的深度 .如下具体显示怎么样创造和绘制分数. 

{
  draw_set_color(c_black);
  d3d_set_projection_ortho(0,0,room_width,room_height,0);
  d3d_set_hidden(false);
  draw_text(10,10,'Score: ' + string(score));
  d3d_set_hidden(true);
}
