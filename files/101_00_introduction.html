你想要创造一个属于你自己的电脑游戏

虽然玩游戏很有趣，但真正有趣的是自己设计游戏并让其他人来玩。在过去，想要自己做游戏比登天还难。现在的商业游戏通常需要10-50人的团队开发一两年。预算基本上都在上百万美元。并且开发团队都是程序员，美工，音效师等专业人员。

但是Game Maker改变了这一切！用Game Maker 你可以飞速地开发电脑游戏并且不用学习编程语言！当然你不要指望几周内就能开发出穿越火线或者地下城与勇士这类游戏。但这并不重要，我们玩游戏不是玩它的复杂性。
我们可以制作一些比如俄罗斯方块啊, 宝石迷阵啊, 还有太空侵略者什么的。这些玩起来都很有趣并且做起来很简单。

Game Maker提供了一个直观的和易于使用的拖放界面。让你很快就能创造出你自己的游戏你可以导入和创建图像，精灵（动图）和音乐，并且使用它们。Game Maker为了你的起步，附带了相当多这样的资源包。你可以很容易地在你的游戏中定义对象，并赋予它们行为，你可以定义在游戏中具有吸引力的房间（关卡）。如果你想取得对游戏的全面控制，这里有一个Game Maker内置的，易于使用的编程语言，可以让你对游戏具有完全控制权

Game Maker一直专注于2D游戏，所以它不是用来制作大型的3D游戏的，即使它还是存在一些弱鸡的3D显示功能。但是你可不要被他绊倒，很多看起来是3D的游戏，其实是用2D的精灵技术实现的，设计二维游戏可是又快又简单的。

Game Maker分为两个版本，精简版和专业版。精简版免费但有很多功能限制，并且会显示弹窗。不过你可以随意地发布用精简版创建的游戏，如果你脸皮够厚，你甚至可以拿去卖。详细信息请参阅附带的许可协议。我们强烈建议你充钱把Game Maker升级到专业版，这将大大拓展Game Maker的功能，运行游戏时，将不再显示logo。这也将支持Game Maker的进一步发展。 有关升级的详细信息，请参阅专业版页面
