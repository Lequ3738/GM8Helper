实例

游戏中，最基本的单位就是各种对象的实例。你可以在游戏进行时更改实例的属性，也可以创建或摧毁实例。我们在之前讨论了许多实例的移动相关变量，后面还要认识一些实例的绘制相关变量，不过每一个实例不仅有移动变量和绘制变量，还有如下的变量：

object_index*对象的索引。这个变量不可以改变。
id*实例的唯一标识（>= 100000）。（注意，在房间编辑器中，鼠标指向的实例会显示id。）
mask_index用作碰撞遮罩的精灵的索引。值为 -1 时默认使用 sprite_index 。
solid实例是否为固体。可以在游戏进行中改变。
persistent实例是否持续显示并且移动到另一房间时再现。有些时候你可能想要切换持续性。（比如你想要返回上一个房间时）

处理实例时有个问题。分辨单个的实例不是很容易，因为他们没有名字。某些特殊对象仅有1个实例，你可以使用对象名来代替id。如果一个对象有多个实例则需要获得实例的 id 。对于实例来说，这是一个唯一的标识符，可以在with语句中当做对象标识符使用。幸运的是这里有大量的变量及程序帮助你定位实例 id。

instance_count*房间中现存实例的数量。
instance_id[0..n-1]*特定实例的 id。这里的 n 是实例的数量 。

注意，实例对instance_id的分配每一步都改变，所以你不能使用上一步的值。举个例子，你的游戏中的每个单位都拥有力量值，但是你想找到力量值最高的那个: 

{
  maxid = -1;
  maxpower = 0;
  for (i=0; i<instance_count; i+=1)
  {
    iii = instance_id[i];
    if (instance_exists(iii))
      if (iii.object_index == unit)
      {
        if (iii.power > maxpower)
          {maxid = iii; maxpower = iii.power;}
      }
  }
}

做完循环后， maxid 就是那个最强的单位了。（循环时不要销毁实例，因为会从数组instance_id中移除已销毁实例而导致出错） 当然，对于这种特殊情况，用以下的代码会更好： 

{
  maxid = -1;
  maxpower = 0;
  with (unit) do
  {
    if (power > maxpower)
      {maxid = self; maxpower = power;}
  }
}

instance_find(obj,n)返回值为参数 obj 的第 (n+1) 个实例 id 。参数 obj 可以是某对象或是关键字all。如果不存在，返回特殊对象noone。注意，instance_id对实例id的分配每一步都会改变，所以你不能使用上一步的值。
instance_exists(obj)返回值为 obj 的实例是否存在。参数 obj 可以是某对象，实例id或是关键字all。
instance_number(obj)返回 obj 的实例的总数。参数 obj 可以是某对象或是关键字all。
instance_position(x,y,obj)返回值为 obj 在（ x ， y ）位置上实例的 id 。同一位置有多个实例时，返回第一个实例。参数 obj 可以是某对象或是关键字all。如果不存在，返回特殊对象 noone 。
instance_nearest(x,y,obj)返回值为最接近（ x ， y ）位置的 obj 的实例 id 。参数 obj 可以是某对象或是关键字all。
instance_furthest(x,y,obj)返回值为离（ x ， y ）位置最远的 obj 的实例 id 。参数 obj 可以是某对象或是关键字all。
instance_place(x,y,obj)返回值为当前实例被放置在位置（x，y）后遇到的obj的id 。参数 obj 可以是某对象或是关键字all。如果不存在，返回特殊对象 noone

下面的函数用于创建销毁实例。

instance_create(x,y,obj)在（ x ， y ）位置创建 obj 的实例。函数返回新实例的id。
instance_copy(performevent)创建当前实例的复制品。参数 performevent 为复制品的创建事件是否必须执行。函数返回新复制品的 id。
instance_destroy()销毁当前实例。
instance_change(obj,perf)将当前实例改变为obj的实例。参数 perf 为是否执行销毁和创建事件。
position_destroy(x,y)销毁所有与点（ x ， y ）发生碰撞的实例。
position_change(x,y,obj,perf)将与点（ x ， y ）发生碰撞的实例改变为 obj 的实例。参数perf为是否执行销毁和创建事件。
