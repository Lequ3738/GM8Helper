拓展变量

你通过对一个变量赋值来创建新的变量（无需先声明，赋值即是声明）。如果你只使用一个变量名来声明变量，该变量将仅仅被储存在对象实例中。所以不要认为在处理另一个对象时可以直接调用它（或者是同一对象的另一个实例）。你可以在另一个对象中设置和读取变量，通过在变量名前面添加对象名称和一个句点"."

【全局变量】使用"global.变量名"的格式创建一个全局变量，所有对象实例都可以调用它。例如，你可以这样写: 

{
  if (global.doit)
  {
    // do something
    global.doit = false;
  }
}

你也可以直接将变量声明为全局变量，格式如下 

globalvar <varname1>,<varname2>,<varname3>, ... ;

一旦执行这样的声明方式，变量将一直是全局形式，并且不需要再加全局变量前缀"global."了。它只需要在一段被执行的代码中声明一次。之后在所有的地方都会被被认为是全局变量

【临时变量】有些时候你希望变量只在当前的代码块或者脚本中使用。用这种方式可以避免浪费内存或命名冲突，同时这种变量也比全局变量速度更快。要使用这种变量你必须在变量名前加入关键字"var"和一个空格。这种声明看起来应该是这样的.

var <varname1>,<varname2>,<varname3>, ... ;

举个例子，你可以这样写： 

{
  var xx,yy;
  xx = x+10;
  yy = y+10;
  instance_create(xx,yy,ball);
}
