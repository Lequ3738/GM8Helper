注册

如果需要储存游戏的少量资讯，还有一个比文件更简单的机制，那就是注册。注册是一 个视窗为了方便维护程式设定的庞大数据库，一个注册包括一个名称和一个数值，可以使用 字串和实数。有以下这些函数可用 :

registry_write_string (名称,字串)用指定的名称和字串在注册创建一个登录。
registry_write_real (名称,实数)用指定的名称和实数在注册创建一个登录。
registry_read_string (名称)返回指定的名称保存的字串(名称一定要存在，否则会返回空 字串)。
registry_read_real (名称)返回指定的名称保存的实数(名称一定要存在，否则会返回0)。
registry_exists (名称)返回该名称是否存在。

实际上，在注册的数值被群组成键，以上的指令作用于特地为游戏创建的键的数值，游戏 程式可以使用这些函数去取得特定的系统资讯，也可以在其他键读物数值，也可以写入数值 但要非常小心，因为这会很容易地破坏你的系统(在安全模式下不允许写入)。须注意键是被 群组起来的，以下的函数预设在群组HKEY_CURRENT_USER工作，但是也可以改变根群组，例 如，如果要找出目前的暂存目录，就用 

  path = registry_read_string_ext('\Environment','TEMP');

有以下的函数可以用 .

registry_write_string_ext (键,名称,字串)用指定的名称和字串在注册的键建立一个注册。
registry_write_real_ext (键,名称,实数)用指定的名称和实数在注册的键建立一个注册。
registry_read_string_ext (键,名称)返回键中指定的名称保存的字串(名称一定要存在，否则会返回空字串)。
registry_read_real_ext (键,名称)返回键中指定的名称保存的实数(名称一定要存在，否则 会返回0)。
registry_exists_ext (键,名称)返回指定的键中指定的名称是否存在。
registry_set_root (根目录)设定使用其他时用到的根目录，使用以下数值 :
0 = HKEY_CURRENT_USER
1 = HKEY_LOCAL_MACHINE
2 = HKEY_CLASSES_ROOT
3 = HKEY_USERS
