吸引器

粒子系统除了发射器还包含了吸引器。吸引器用来吸引粒子（或推开它们）。一个粒子系统可以拥有多个吸引器。推荐你不要用太多，因为它们会减慢对粒子的处理速度。一个吸引器有下列属性 :
  • x,y 设定吸引器的位置 。
  • force 设定吸引器的力度。力度怎样作用于粒子取决于下列参数 。
  • dist 设定吸引器有效的最大距离。只有靠近这个距离的粒子才会被吸引 。
  • kind 设定吸引器的种类。有以下值
    • ps_force_constant 设定力度为常量，不受距离影响。即恒力。
    • ps_force_linear 设定一个线性成长的力度。在最大距离时力度为 0 ，到达吸引器的位置时达到给定值 。
    • ps_force_quadratic 设定力度为曲线地 ( 二次方的 ) 增长 。
  • additive设定力度为每步附加到速度和方向（ true ）还是仅仅应用到粒子位置上（ false ）。 addtive 的值为 true 时粒子向吸引器方向加速，为 false 时粒子恒速移动。

下列函数用于定义吸引器。注意，每个吸引器的第一个参数都是粒子系统的索引名。

part_attractor_create(ps) 创建指定粒子系统的吸引器。返回值为吸引器的索引名。设置吸引器的其他属性时需要调用到索引名。
part_attractor_destroy(ps,ind) 销毁粒子系统的吸引器 ind 。不再使用时记得调用这个函数来释放空间。
part_attractor_destroy_all(ps) 销毁粒子系统创建的所有吸引器。
part_attractor_exists(ps,ind) 返回值为指定粒子系统的吸引器是否存在。
part_attractor_clear(ps,ind) 清除吸引器 ind 并恢复到默认设置。
part_attractor_position(ps,ind,x,y) 设置吸引器 ind 的位置为（ x ， y ）。
part_attractor_force(ps,ind,force,dist,kind,aditive) 设置吸引器 ind 的力度参数 。
