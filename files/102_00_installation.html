介绍

你可能已经安装Game Maker了，但如果没有，这里是教你如何安装Game Maker 的。你只需要运行gmaker80.exe，然后跟着屏幕上的介绍走。你可以将它安装在任何你喜欢的地方，不过最好是安装在默认路径。完成安装后，在开始菜单中，你会找到一个新的程序组Game Maker ，然后你就可以打开它，读到我们现在的这份教你安装的帮助文档了

Game Maker 还安装了相当数量的图像，精灵（动图）和音效在你的电脑上，它可以在你的游戏中免费使用。一些示例游戏也被安装了。所有的这些都可以在你安装Game Maker的本地文件夹中找到。

你第一次运行Game Maker时会被询问要使用简单或高级两种模式中的哪一种模式，如果你以前没有使用过游戏制作引擎，并且不是一个老程序员，你最好选择简单模式(选择否)。在简单模式下显示的选项较少。你以后可以很容易地从菜单选单中切换到高级模式。

你将会在窗口右方看见一个教程。这个教程将教你如何快速创建你的第一个游戏，引导你完成Game Maker的基本使用方法。在使用Game Maker前强烈建议你根据教程操作。如果你跳过了，之后可以从帮助选单中重新学习教程

配置需求

任何一台10年内的电脑都可以完美运行Game Maker。

详细地来说，Game Maker 要求的系统版本为win2000,winxp，win7或更高。创建游戏所需要的显卡至少能兼容DirectX 8(或更高)，至少拥有32m显存，至少需要一个800×600大小，65000色（16位色，最好是真彩色）的显示器，另外一个DirectX 8的兼容声卡是必需的。请确保你有安装最新的驱动程序。 Game Maker 需要你的计算机上安装有DirectX8.0或更高版本。（你可以从微软网站中下载DirectX的最新版本： http://www.microsoft.com/windows/directx/）。当设计和测试游戏时，对内存的要求是相当高的（至少128MB，或者更高，取决于操作系统）如果只是运行游戏，内存要求不那么苛刻，需求的多少，取决于游戏类型。
