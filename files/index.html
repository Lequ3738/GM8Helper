Game Maker 编程语言（已译完，修改中）

Game Maker包含一个内置的编程语言，比标准动作提供了更多的灵活性和控制力，这种语言我们称之为GML（Game Maker Language）。在本章中，我们将讲解GML语言，并概述可用于控制游戏所有方面的函数和变量（接近1000个）。
