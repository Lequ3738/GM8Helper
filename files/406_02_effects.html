声音效果

只有 Game Maker 注册版本才能使用这些函数。

声效可以改变声音和背景音乐的效果。只有 wave 和 midi 才能使用声效， mp3 不能用。这部分内容介绍使用和改变声效的函数。要使用这些函数的话，最好理解声音和合成的工作原理。这里不给出不同参数的解释。自己翻书或是网上找进一步的介绍 。

给声音添加声效的方法为定义声音资源时指定或者使用下列函数

sound_effect_set(snd,effect) 设置指定声音的声效。参数 effect 可以为以下值 :
se_none 无
se_chorus 合声
se_echo 回声
se_flanger 消噪
se_gargle 漱口声
se_reverb 混响
se_compressor 压缩器
se_equalizer 均衡器
可以通过添加多个值设置混合的效果。比如，你可以用

sound_effect_set(snd,se_echo+se_reverb);

来得到一个回声和混响混合的效果

所有的效果都有一些默认的设置。一旦一个效果应用到声音上，你就可以改变一些设置。这里的顺序非常重要。首先将效果应用到声音上，然后再设置参数。一旦你再运用效果，就需要重新设置一下。注意，所有的参数必须有特定的范围，下面介绍。下列函数用于改变效果参数 :

sound_effect_chorus(snd,wetdry,depth,feedback,frequency,wave,delay,phase) 为指定的声音设置和声效果的参数。参数设置有下列几种 :
wetdry 为 wet （处理过）和 dry （未处理）的信号比。（范围： 0 到 100 ，默认 50 ）
depth 由低波振荡器调整延迟时间，以百分比计算。（范围： 0 到 100 ，默认 25 ）
feedback 为输出信号反馈到效果输入的百分比。（范围： -99 到 99 ，默认 0 ）
frequency 为 LFO （低频振荡器）的频率。（范围： 0 到 10 ，默认 0 ）
wave 为 LFO 的波形。（ 0 为三角形， 1 为波形，默认 1 ）
delay 为输入延迟的毫秒数。（范围： 0 到 20 ，默认 0 ）
phase 为 LFO 的左右相位。（范围： 0 到 4 ，默认 2 ）
sound_effect_echo(snd,wetdry,feedback,leftdelay,rightdelay,pandelay) 为指定的声音设置回声效果的参数。参数设置有下列几种 :
wetdry 为 wet （处理过）和 dry （未处理）的信号比。（范围： 0 到 100 ，默认 50 ）
feedback 为输出信号反馈到效果输入的百分比。（范围： 0 到 100 ，默认 0 ）
leftdelay 为左声道延迟，单位毫秒。（范围： 1 到 2000 ，默认 333 ）
rightdelay 为右声道延迟，单位毫秒。（范围： 1 到 2000 ，默认 333 ）
pandelay 为连续回声是否交换左右延迟（ 0 为不交换， 1 为交换，默认 0 ）
sound_effect_flanger(snd,wetdry,depth,feedback,frequency,wave,delay,phase) 为指定的声音设置去噪效果的参数。参数设置有下列几种 :
wetdry 为 wet （处理过）和 dry （未处理）的信号比。（范围： 0 到 100 ，默认 50 ）
depth 由低波振荡器调整延迟时间，以百分比计算。（范围： 0 到 100 ，默认 25 ）
feedback 为输出信号反馈到效果输入的百分比。（范围： -99 到 99 ，默认 0 ）
frequency 为 LFO （低频振荡器）的频率。（范围： 0 到 10 ，默认 0 ）
wave 为 LFO 的波形。（ 0 为三角形， 1 为波形，默认 1 ）
delay 为输入延迟的毫秒数。（范围： 0 到 20 ，默认 0 ）
phase 为 LFO 的左右相位。（范围： 0 到 4 ，默认 2 ）
sound_effect_gargle(snd,rate,wave) 为指定的声音设置漱口声效果的参数。参数设置有下列几种 :
rate 为调制的比率，单位赫兹。（范围： 1 到 1000 ，默认 1 ）
wave 为调制波的形状。（ 0 为三角形， 1 为方形，默认 0 ）
sound_effect_reverb(snd,gain,mix,time,ratio) 为指定的声音设置混响效果的参数。参数设置有下列几种 :
gain 为信号的输入，单位分贝（ dB ）。（范围： -96 到 0 ，默认 0 ）
mix 为混响混合，单位 dB 。（范围： -96 到 0 ，默认 0 ）
time 为混响时间，单位毫秒。（范围： 0.001 到 3000 ，默认 1000 ）
ratio 为频率比。（范围： 0.001 到 0.999 ，默认 0.001 ）
sound_effect_compressor(snd,gain,attack,release,threshold,ratio,delay) 为指定的声音设置压缩器的参数。参数设置有下列几种:
gain 为压缩后的输出信号。（范围： -60 到 60 ，默认 0 ）
attack 为到达压缩最大值前的时间。（范围： 0.01 到 500 ，默认 0.01 ）
release 为输入降到阀值的压缩停止的速度。（范围： 50 到 3000 ，默认 50 ）
threshold 为压缩开始的峰值，单位分贝。（范围： -60 到 0 ，默认 -10 ）
ratio 为压缩比。（范围： 1 到 100 ，默认 10 ）
delay 为到达初相位的阀值之后的时间，单位毫秒。（范围： 0 到 4 ，默认 0 ）
sound_effect_equalizer(snd,center,bandwidth,gain) 为指定的声音设置均衡器的参数。参数设置有下列几种 :
center 为中心频率，单位赫兹。（范围： 80 到 16000 ）
bandwidth 为带宽，单位半音程。（范围： 1 到 36 ）
gain 为倍率。（范围： -15 到 15 ）
