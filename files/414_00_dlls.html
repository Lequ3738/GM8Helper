使用 DLL

这个函数仅在注册版Game Maker中使用.

不仅仅在版本7中有这个扩展机制,你是鼓励使用这种扩展机制,而不是函数,在本节中说明.看 http://www.yoyogames.com/extensions介绍.这个函数.这些职能主要是与过去留在兼容性

在某些事例中的GML函数是不能够使你如愿, 其实你可以扩展可用性插件. 一个来自一个DLL文件的插件的方式(动态链接库) . 在这样的一个DLL文件,你可以定义的函数. 这种函数的程序可以使用任何编程语言,支持创建DLL文件(例如Delphi,C, C++, 等等) ,你虽然还需要有一定的编程技巧,以做到这一点. 插件功能必须有一个特定的格式. 他们可以有介于0和16个参数, 每一项可以是一个实数(C中的double) ,或一个NULL结尾的字符串. (超过4参数 只有这样,此刻才能支持的真正参数) . 他们必须回到要么是一个real或NULL结尾的字符串.

在  Delphi 中你创建一个Dll首先选择在文件菜单下的新建并悬着Dll。这儿有一个DLL例子你可以使用Game Maker在Delphi（注意Delphi代码，而不是GML代码） 

library MyDLL;

uses SysUtils, Classes;

function MyMin(x,y:double):double;  cdecl;
begin
  if x<y then Result := x else Result := y;
end;

var res : array[0..1024] of char;

function DoubleString(str:PChar):PChar; cdecl;
begin
  StrCopy(res,str);
  StrCat(res,str);
  Result := res;
end;

exports MyMin, DoubleString;

begin
end.

这个Dll定义了两个函数。MyMin 有2个参数并返回小的那个。还有 DoubleString 是双字符串。注意到你要小心内存管理. 这就是为什么我声明全局的字符串. 还注意使用了cdecl调用约定. 你可以使用cdecl或stdcall调用约定. 一旦你建立的DLL在Delphi中你会得到一个lMyDLL.DLL文件. 这个文件必须放置在目录中运行你的游戏. (或你的windows可以找到它的任何其他地方) .

在 Game Maker中使用Dll首先需要特殊的扩展函数如果你想使用并执行那些参数。使用下面的GML函数。

external_define(dll,name,calltype,restype,argnumb,arg1type,arg2type, ...) 定义一个扩展函数.dll 是DLL文件的文件名，name是功能函数的名字，calltype使用呼叫的协定（方式），它有两种方式分别为dll_cdel或者 dll_stdcall。restype是结果的类型，它也有分为两种类型ty_real或者ty_string。argnumb是参数的个数（0-16 个之间）。下一步，对于每个参数你必须指定它的类型，你可以再使用ty_real或者ty_string。当有四个以上的参数是所有它们的类型必须都为 ty_real。

调用DLL中的函数时函数本身返回到这个函数的id值，这个id值很重要因为它在后面会被访问到。比如在一个例子中，在游戏开始时你可能要使用到下列GM代码：: 

{
  global.mmm = external_define('MyDLL.DLL','MyMin',dll_cdecl,
                                     ty_real,2,ty_real,ty_real);
  global.ddd = external_define('MyDLL.DLL','DoubleString',dll_cdecl,
                                     ty_string,1,ty_string);
}

做完上一步，现在你可以决定你是否要访问外部功能函数来操作数值字符,从而实现某个功能，你可以使用下面的函数：:

external_call(id,arg1,arg2,...) 呼叫外部指定id的外部函数，后面跟上参数。你必须要给出正确的参数个数和每个参数的类型（数值还是字符）。这个函数本身返回外部函数操作后的结果。

可以再看一个例子: 

{
  aaa = external_call(global.mmm,x,y);
  sss = external_call(global.ddd,'Hello');
}

当你不再想使用DLL时你最好把它释放掉。

external_free(dll) 你可以在游戏中释放掉指定文件名的DLL文件。某些特殊需要你删除了dll，同时dll没有被释放的话是不能被删除的.最好记得这个步骤,特别是在游戏结束时.

你可能会想知道如何在一个DLL文件库中编制一个在游戏中起某些作用函数,例如你可能想建立一个DLL文件用来增加一个物体在游戏中的实例,要实现 的最简单的方法是让你的DLL函数返回一个包含有一段GM语言的代码,然后用下列函数来执行这个字符(也即执行这段GM代码).

execute_string(str,arg0,arg1,...) 显示参数执行一段代码

或者你也可以让创建的DLL文件执行一个脚本(此函数也用来修改后的行为游戏) .

execute_file(fname) 执行文件中的代码

现在你能访问一个扩展函数并且执行字符串如下: 

{
  ccc = external_call(global.ddd,x,y);
  execute_string(ccc);
}

在某些情况下,你的DLL可能需要知道处理的主要窗口图形的游戏. 这可使用下列功能,然后才能通过的DLL文件:

window_handle() 返回主要窗口的句柄.

注意DLL文件不能在游戏安全模式(secure mode)下使用.

DLL插件确实是一非常强有力的工具,但建议你在理解熟悉它后,觉得有必要时再使用,一般GM提供的功能完全足以应付大多数游戏制作.
