贴图

现在你已经明白怎样在房间里添加贴图。贴图是背景资源的一部分。贴图只是可见的一些图 像。他们并不会产生事件或者碰撞。所以贴图的执行速度要比对象快许多。任何不需要产生 事件或者碰撞的物体最好都设定成贴图。同时，在产生碰撞事件的简单对象中使用精美的图 块图像也是不错的选择。

你可以控制贴图的能力要比你想象的大得多。你可以在设计房间得时候添加他们，但你也可 以在游戏运行过程中添加他们。你可以改变他们得位置，甚至缩放他们得大小或让他们部分 透明。一个贴图拥有如下几个属性 :

  • background. 要调用贴图的背景资源名称。
  • left, top, width, height. 要调用贴图的背景区域。
  • x,y. 贴图在房间放置的位置，x,y 为贴图左上角的坐标。
  • depth. 贴图在房间里的深度。你可以选择任意深度，让贴图在对象实例之间显示。
  • visible. 贴图是否可见。
  • xscale, yscale. 贴图的纵横缩放比。（默认为 1 ，不缩放）
  • blend. 用来混合绘制贴图的颜色。
  • alpha. 贴图的阿尔法透明通道值。 1 代表不透明；0 代表完全透明。
要改变贴图的属性你需要先指定贴图的 id 。当你在房间中添加贴图时，窗口底部的信息栏 将会显示贴图的 id 。同时也有一个函数可以找到贴图的 id 。

以下几个函数负责处理贴图相关操作 :

tile_add(background,left,top,width,height,x,y,depth) 在房间中添加新的贴图。函数 返回生成贴图的 id 。
tile_delete(id) 删除指定 id 的贴图。
tile_exists(id) 返回指定 id 的贴图是否存在。

tile_get_x(id) 返回指定 id 的贴图的 x 横坐标。
tile_get_y(id) 返回指定 id 的贴图的 y 纵坐标。
tile_get_left(id) 返回指定 id 的贴图的 left 左边属性值。
tile_get_top(id) 返回指定 id 的贴图的 top 顶边属性值。
tile_get_width(id) 返回指定 id 的贴图的 width 宽属性值。
tile_get_height(id) 返回指定 id 的贴图的 height 高属性值。
tile_get_depth(id) 返回指定 id 的贴图的 depth 深属性值。
tile_get_visible(id) 返回指定 id 的贴图的 visible 可视属性值。
tile_get_xscale(id) 返回指定 id 的贴图的 xscale x比例属性值。
tile_get_yscale(id) 返回指定 id 的贴图的 yscale y比例属性值。
tile_get_background(id) 返回指定 id 的贴图的 background 背景属性值。
tile_get_blend(id) 返回指定 id 的贴图的 blend 混合属性值。
tile_get_alpha(id) 返回指定 id 的贴图的 alpha 透明度属性值。

tile_set_position(id,x,y) 设置指定 id 的贴图的坐标为(x,y)。
tile_set_region(id,left,right,width,height) 设定指定 id 的贴图在背景上的矩形区域。
tile_set_background(id,background) 设定指定 id 的贴图的背景 background 。
tile_set_visible(id,visible) 设定指定 id 的贴图是否可见。
tile_set_depth(id,depth) 设定指定 id 的贴图的深度。
tile_set_scale(id,xscale,yscale) 设定指定 id 的贴图的缩放比。
tile_set_blend(id,color) 设定指定 id 的贴图的混合颜色。只在注册版本中使用。
tile_set_alpha(id,alpha) 设定指定 id 的贴图的阿尔法透明通道值。

以下函数处理贴图的层次，就是同一深度下的贴图叠加操作

tile_layer_hide(depth) 隐藏指定深度 depth 的所有贴图。
tile_layer_show(depth) 显示指定深度 depth 的所有贴图。
tile_layer_delete(depth) 删除指定深度 depth 的所有贴图。
tile_layer_shift(depth,x,y) 移动指定深度 depth 下的所有贴图向坐标(x,y)移动。可以 用来搭建卷轴移动的贴图层。
tile_layer_find(depth,x,y) 返回给定深度 depth 下，坐标(x,y) 的贴图 id 。如果没有 找到则返回 -1 。如果有多个结果则返回第一个的 id 。
tile_layer_delete_at(depth,x,y) 删除指定深度 depth 下，坐标(x,y) 的贴图。如果有 多个结果则全部删除。
tile_layer_depth(depth,newdepth) 将指定深度 depth 下的所有贴图的深度更改为新的深 度 newdepth 。
