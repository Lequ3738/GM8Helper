转变

转变语序你你改变在世界中绘制物体的位置.例如函数绘制方块仅仅绘制平行方块.首先设置旋转转变你能创造一个旋转方块.精灵也总得绘制在xy面. 你可以更改设定此一转变. 有两种功能:设定转变函数和增加转变函数.

d3d_transform_set_identity() 设置转变id(无转变).
d3d_transform_set_translation(xt,yt,zt)设置转变到移动向设定方向.
d3d_transform_set_scaling(xs,ys,zs) 设置转变尺寸.
d3d_transform_set_rotation_x(angle) 设置在x轴上的旋转.
d3d_transform_set_rotation_y(angle) 设置在y轴上的旋转.
d3d_transform_set_rotation_z(angle) 设置在z轴上的旋转.
d3d_transform_set_rotation_axis(xa,ya,za,angle) 设置以方向(xa,ya,za)上旋转角度angle.
d3d_transform_add_translation(xt,yt,zt)增加方向上移动.
d3d_transform_add_scaling(xs,ys,zs) 增加尺寸.
d3d_transform_add_rotation_x(angle) 增加x轴上的旋转.
d3d_transform_add_rotation_y(angle) 增加y轴上的旋转.
d3d_transform_add_rotation_z(angle) 增加z轴上的旋转.
d3d_transform_add_rotation_axis(xa,ya,za,angle) 增加以方向(xa,ya,za)上旋转角度angle。
真实旋转和尺寸在原始世界,没有改变物体绘制.如果物体没有在原始移动到了不是我们所想的不同的地方.因此如旋转物体超过我们自己的x轴,我们必须首先转变原始的它,再旋转它,最后方位它的坐标.那些增加转变的函数也是如此.

这个例子可能更好解释.spr时精灵在点(100,100,10)绘制,我们能使用如下代码实现. 

{
  d3d_transform_set_translation(100,100,10);
  draw_sprite(spr,0,0,0);
  d3d_transform_set_identity();
}

注:因为我们使用转变我们应该在(0,0)绘制精灵(假定正确对象在深度0!如果你不能确定首先设定的深度)如果你将使用第一人称射击我们将不能看 到这个精灵.原因是这仍然在xy平面上,我们希望旋转90延x轴或者y轴.因此我们需要增加一个旋转它.因此我们可以使用下面的代码. 

{
  d3d_transform_set_identity();
  d3d_transform_add_rotation_x(90);
  d3d_transform_add_translation(100,100,10);
  draw_sprite(spr,0,0,0);
  d3d_transform_set_identity();
}

有些时候你向保存正确的转变,如增加了一个转变并返回旧的(这经常发生当绘制水平模式时).最后你能压出正确的转变在一个堆栈和旧堆栈里做再次的正确转变.如存在下列函数:

d3d_transform_stack_clear() 清除转变堆栈.
d3d_transform_stack_empty()返回转变堆栈是否为空.
d3d_transform_stack_push() 压出在堆栈中正确的转变.返回是否压出堆栈在这个房间中(如果你忘记了曾经的转变你在堆栈下某些时候会离开房间)。
d3d_transform_stack_pop() 曾经上一个转变从堆栈中正确完成它,返回是否有一个这样的转变在堆栈中.
d3d_transform_stack_top() 正确完成最顶上的转变但是并不从堆栈中移出它,返回时否有这样一个转变在堆栈中.
d3d_transform_stack_discard() 删除堆栈最顶上的转变,但是并不执行它.返回是否有这样的一个转变在堆栈中.

使用转变是很强大功能,但是必须小心和总是设置转变返回id在你使用时.
